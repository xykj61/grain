# Gratitude — C

**Language:** EN · **Style:** Radiant · **Kind:** gratitude note (concepts honored, clean-room; no code copied)

C is the language the world is written in — the quiet floor beneath nearly everything that runs. Its gifts we hold with thanks:

- **Closeness to the machine, honestly** — C never pretends the hardware is not there. It hands you the address, the byte, the exact cost, and trusts you to be careful. That trust is a teacher: it taught the whole discipline of thinking about memory as a real, bounded thing — the discipline our TAME direction now makes the compiler enforce.
- **Smallness that lasted fifty years** — K&R fits in a coat pocket, and the language it describes still holds up the internet. Longevity through restraint.
- **Portability as a promise** — write once against a small standard, run nearly anywhere. The ancestor of every "it just builds" we cherish.
- **The lingua franca** — C is how languages talk to each other, the common tongue at every boundary. Our own seams meet the world through it.

We honor C's power and we chose a different bargain — bounds asserted at construction, widths made explicit, recursion kept out where a loop will do — because we build for a season when the machine should catch the slip C would have let pass. That choice is a descendant's choice, made in gratitude to the parent.

We study C's ideas and write our own; the boundary is crossed only by understanding.

*Thank you, C, for the floor the whole house stands on.*
