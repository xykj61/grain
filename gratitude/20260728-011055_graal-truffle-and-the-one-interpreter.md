## The Gratitude

Our thanks to **Oracle Labs and the GraalVM and Truffle communities** — the researchers and engineers who made a generation of language builders believe a simple, radical sentence: *write the interpreter, and the compiler comes.* Truffle lets a language live as a self-optimizing tree interpreter; the Graal compiler partially evaluates that interpreter against a program at run time — the first Futamura projection made industrial — producing specialized machine code, and when a speculation fails, **deoptimization** hands execution honestly back to the interpreter to learn again. One definition, many speeds, no second truth.

## Siloed Along Our Grain

**One — one definition, two roads, is our oldest instinct confirmed.** Truffle's whole premise is that the interpreter is the single source of meaning and every faster form is derived from it. Our lowerer already lives this in miniature: `emit` and `expect` are two roads out of one parsed spec — the emitted program and the numeric twin can never drift, because neither is written twice. The f1 round audits every seam where a second truth could creep and names each with a witness.

**Two — the numeric expect is a tiny partial evaluator, and we should say so.** `walk_expect`, `tree_expect_at`, `pilot_expect` — each folds the program against a known sample at counsel time, which is exactly partial evaluation's move: run what is known, keep what is not. Naming the kinship gives the fixture road its theory and charts its growth: the more the desk declares statically, the more the expect can fold ahead of the build.

**Three — speculate loudly, fall back honestly.** Deoptimization is the humility built into Graal's speed: optimized code carries guards, and a failed guard returns to the slow truth rather than lying fast. Our static cousin is refusal-first walls — yet the lesson cuts forward: any future Grain fast-path (caches, memoized folds, the far-day JIT question) must carry its guard and its named road back, or it does not land.

**Four — measure after the fold, never before.** Truffle's inlining matured when it stopped trusting AST node counts and started counting compiler nodes *after* partial evaluation — the honest size is the size after the machine has done its thinking. That is pin-what-the-bench-reports as a compiler-engineering principle, and it seats the fascia metric's law: fascia grades the weave by measured post-fold signals, never by guessed pre-fold ones.

**Five — polyglot by shared protocol, not shared blood.** Truffle languages interoperate because every interpreter speaks one interop protocol, so tools work across all of them. Our one-value-model and the Brix descriptor law are the same bet at our scale: values compose across module seams without reserialization, and any tool that can split lines can read the descriptor.

## The Difference We Keep

Graal buys its magic with a great virtual machine beneath; Grain owns the whole floor, bounded and bare. We decline the machinery and keep the philosophy: the interpreter-first truth, the honest fallback, the post-fold measure. Rounds f1–f2 run these five against the weave and pin what they find.
