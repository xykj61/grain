**Kabir** is the editor this tree would write if it wrote one, and **`kab`** is the word a hand types
to open it.

## Why that name, and why it is not a new coinage

Kabir already stands in this tree. The Inner Scope charter names him among its inspirations --
*named, not quoted* -- beside Rumi, Hafez and Ibn Arabi. Choosing him here continues something rather
than starting it.

He was a **weaver** by trade, and that is the whole argument. **Mantra was named for the weave.**
An editor named for a weaver, sitting over a version-control projection named for the weave, is one
image carried in two places rather than two images competing. The [Comlink tendency](../.claude/rules/comlink-tendency.md)
asks for the clearest, warmest, safest word at whatever length it wants; Kabir is a plain name a
newcomer can say, it collides with no seated module, and `kab` is free across the whole tree
(checked `20260908.021022`).

He also wrote in the vernacular rather than the priestly language, for people who could not read the
scholars. That is the register this tree already writes in.

## The one idea worth carrying

**Show the cloth before you cut it.** The object is selected and made visible; the verb then acts on
something the person can already see. Everything below follows from that and nothing below is a
keymap.

This tree argues the same thing in a room that has nothing to do with editors. A scan prints the
repair it computed; the tool applies exactly that and nothing else. A census names what it counted
before a ceiling refuses. The editor would be that habit given a cursor.

## Where it would sit among what we already have

| Ours | What it would carry |
|---|---|
| **Rye** | the buffer, the selection set, the undo record -- bounded, explicit widths, named errors |
| **Glow** | the editing grammar itself, as runes; the terms a person types and a script composes are one set |
| **Rishi** | the seam to the world -- a selection handed to a program and taken back, `run` returning a status checked before the output is trusted |
| **Caravan** | the session: a long-lived process, thin attachments, and capabilities that can be conferred and revoked while it runs |
| **Mantra** | what a buffer IS -- a projection over the weave rather than a file the editor owns |
| **Skate / Surf** | the drawing surface, where a terminal is one backend rather than the assumption |

**Caravan is the reason this is interesting rather than ordinary.** An editor is usually a program
that opens files. Over Caravan it is a *supervised session* whose reach is granted and can be taken
back mid-run -- an attachment that may read a buffer and not the disk, or write one path and no
other. That is a sentence no editor in the world can say today, and it is ours already.

**Mantra is the second reason.** If a buffer is a projection over the weave rather than a file, then
undo, history, and blame stop being editor features and become what the projection already does.

## What it would refuse, named now rather than when asked

A code editor. **Not** a file browser, an IDE, a window manager, a terminal multiplexer, or a mail
client. **No embedded scripting language** -- Glow is the language and Rishi is the shell, and adding
a third would be this tree writing the same rule twice. **No plugin binaries.** **No threading in the
core**; Caravan supervises processes and that is where concurrency lives.

## The honest cost, before anyone is enthusiastic

The editor being learned from has run since 2011 with a maintainer and contributors. Buffer
representation, undo, incremental redisplay, terminal capabilities, input decoding, and encoding are
each real bodies of work and **none of them is the interesting part**. The grammar is perhaps a tenth.

**So this page argues for a name and a shape, and against a build.** It is filed as vision.

## The priority call, and the reason

**Yonder -- deferred yet alive.** I choose it rather than a place on the live card, and the reason is
arithmetic rather than taste.

`construction/ITINERARY.md` stands at **40,942 bytes of its 40,960 ceiling** with three bookings
already carried as one-line pointers, and its INNER LOOP section alone is three quarters of it. A
fourth booking would displace a fold that has not been earned. More to the point, the tree's own
[finishing edge](../.claude/rules/lindy-first-crux.md) asks that one real thing ship before the next
is named, and the live card already holds an operator manual, a molt grant, and a table-store
research lap, none of them finished.

**What would move it to the live card**, stated so the decision is checkable rather than permanent:
a real need. If Glow grows a rune surface that wants an editor to exercise it, or if Caravan's
confer-and-revoke wants a first resident that is not a test, Kabir becomes the obvious place to prove
both. Until one of those arrives, an editor is the most enjoyable thing to build and not the most
useful, and this page exists so that when the day comes the name and the shape are already settled.

*May the cloth always be visible before the cut.*
