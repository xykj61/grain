## The grade

The grade runs from 0 to 100, printed with four decimal places. The stored value is a count of ten-thousandths: 0 prints as `0.0000`, and 1000000 prints as `100.0000`. One step is 0.0001.

The width is `u32`. [`../../../context/TAME_GUIDANCE.md`](../../../context/TAME_GUIDANCE.md) gives `u32` to an in-memory count bounded by a named constant. The named ceiling is 1000000, because the grade stops at 100. A power-of-two ceiling of 1048576 would admit a grade past 100, so the program's bound stays 1000000 and the type stays `u32`.

The cell is that integer. The decimal point is only how the meter prints. The same bytes, the same signals, the same integer.

Today the meter still does whole-number arithmetic. In [`../../../tools/fixtures/f/fascia_metric_v0.sh`](../../../tools/fixtures/f/fascia_metric_v0.sh) the grade is `100 - clutter`. The four clutter signals have to move in smaller steps before the printed face grows finer. Until they do, the honest print is the whole number the script already writes.

## The file count
