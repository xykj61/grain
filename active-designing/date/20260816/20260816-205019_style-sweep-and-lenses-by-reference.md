## Move one -- the style sweep before every send

Before each commit, an autonomous round sweeps its own prose -- code comments, Markdown, and prose generally -- Radiant by day, Twilight on the rare night or devotional piece. Lead with what is, active voice, `yet`/`however` over `but`, a benediction only where earned; ordinary and technical prose still ends plainly.

The sweep changes **register, never a claim**. Numbers, paths, stamps, and modality counts hold exactly -- the same invariant `claim_preserve_witness` already guards for a hand's Radiant pass. This is the guardrail that keeps an editing pass from becoming a quiet rewrite of the record.

It lives in seed **section 6** (the clock-ledger-remotes-signing block, where every other pre-send discipline already sits) and in both loop prompt lines of `tools/launch-claude-season.rish`, so a loop that reads only the pasted one-liner still carries it.

## Move two -- lenses by reference, and the paths a loop forgets

The prompt loads the disciplines by **path**, not by paraphrase, because a paraphrase drifts from its source the moment the source moves -- and references are promises the tree keeps. Seed **section 1** now names, beyond the standing lenses, the six a loop most often forgets:

- **Reds ledger** (`work-in-progress/REDS.md`) -- a red books the allocation before new work.
- **Cairns ledger** (`work-in-progress/CAIRNS.md`) -- mark the way back before a breach rename or a seated debride.
- **Docs stay synced** (`.claude/rules/docs-implementation-sync.md`) -- the doc moves in the same commit as the behavior it describes.
- **Prove before GREEN** -- the module witness plus `tools/tame_style_check.rish` and `tools/width-check.rish`, run before any GREEN claim.
- **Loom capture** -- a `loom key=value` line when a round measures a hot path, from real measurement.
- **Style sweep** -- the guides for move one (`context/RADIANT_STYLE.md`, `context/TWILIGHT_STYLE.md`).

## Why silo the technique here

The craft study belongs in external-research, where we read the world with attribution; the technique belongs here, where we name only our own modules. Keeping the two apart is the clean-room path the tree already walks -- understanding crosses the boundary, code and method do not. A future loop lifts this file whole, and the study stays a study.

## The shape, so the next fill inherits it

The seed is the living form; each dated version in `recursion-prompts/versions/` is a filled instance kept as testimony. Evolving the loop means filling a fresh version, not editing the one-liner from memory -- so this technique, once seated, rides into every run that fills the form next.
