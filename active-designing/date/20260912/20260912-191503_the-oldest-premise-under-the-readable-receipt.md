**Stamp:** `20260912.191503` (EDT)
**Language:** EN
**Style:** Gauge, Field setting
**Voice:** Kyri

## The question

What must remain true beneath **The receipt you can read**, even if every current module and
interface disappears?

The living product card answers with a signed offer fact, bounded replay, two projections, and a
visible frame. Reading backward reveals an older promise beneath that mechanism: the record belongs
with the person whose value it describes. A readable receipt keeps that promise only when the person
can hold the receipt itself.

## The source chain, newest to oldest

The current [Linengrow itinerary](../construction/LINENGROW_ITINERARY.md) makes the first whole local
and synthetic. It signs, appends, bounds, projects, renders, verifies, and refuses incomplete input.
The later bundle milestone carries the complete history away.

The [receipt cloth](20260912-142909_the-linengrow-receipt-cloth-design-system.md) keeps deciding
fields visible and personal fields folded. Its first whole promises one signed value receipt, while
its portable bundle arrives later.

The [custody-first principle](../foundations/20260724-200912_nothing-to-give-custody-first-principle.md)
says every data feature names what it minimizes, where keys live, and how deletion remains ordinary.
That is a standing gate, including for a synthetic first resident.

The oldest deciding premise in this chain is [The Roots Beneath the Work](../foundations/20260628-140812_the-roots-beneath-the-work.md),
written `20260628`. It joins three promises: identity begins with a key in the person's hand; truth is
an append-only log of signed facts the person can inspect; holding lightly leaves the door out open.
These promises predate every module named by the current milestone.

## Judgment, oldest to newest

The old premise still decides product behavior. Deferring the complete history bundle is sound: the
first whole stays small, and no network, money, or real identity enters. Yet the signed receipt is
already a complete product artifact. If the first whole displays it while keeping its bytes inside
an application-owned projection, the interface demonstrates custody without giving custody.

The disposition is **revived**. Incense's one-page contract for the first whole should require four
things from the same synthetic case:

1. Name the synthetic holder and the key that signs the offer fact.
2. List the minimum fields retained for this one purpose.
3. Emit the authenticated receipt bytes through an explicit local save or standard-output seam.
4. Re-read those emitted bytes to reproduce the same Linengrow meaning and Dimeroll intake.

This adds no module and opens no custody gate. It sharpens the existing round-trip proof at the
artifact boundary. The later portable bundle still owns complete-history export, import, and
cross-machine rebuilding.

## Evidence and handoff

The chain spans `20260628` to `20260912`: person-held key, inspectable signed fact, minimal custody,
readable receipt, then portable history. All four sources agree once the first receipt itself is
treated as something the holder receives rather than only something the application renders.

Incense owns the contract. Patchouli, Pheromone, Diffuser, and Dimeroll need no new assignment until
that contract names the emitted artifact and its exact fields.
