A guard answers a question about **the tree**. Many guards find their population by walking the
filesystem, and a filesystem holds more than a tree: it holds whatever the last hour of work left
lying around. This is the lap that counts the distance between those two things.

## What came before, in one paragraph

REDS `%722` caught the gap by living through it. A lap verifying an unrelated repair in a worktree
at `.lap/verify` watched its own rostered pass take `rye_harness_roster` from `unresolved=1` to `2`,
one past a ceiling with no slack, and the second `unresolved` named the same file as the first --
counted twice because it stood on disk twice. Planted afterward, a copy of `mantra/` under
`.lap/probe/` took `copy_sameness` from `verdict=ok` to `verdict=drift`. Both guards were repaired to
ask `git check-ignore`. The row closed there and named the rest a lap: **twelve more tree-rooted
walks stood unprobed.**

## Why a meter rather than twelve probes

A hand can probe twelve guards. Probing them buys twelve answers, and the thirteenth walk written
next week arrives unmeasured -- which is where the two that fired came from. So the lap builds the
reading instead: `tools/fixtures/i/ignored_walk_scan.sh` reads the class from the tracked listing, so
a walk written tomorrow is counted the day it lands.

**Its own list of sources comes from `git ls-files`**, for exactly the reason it exists.

## The repair that rode along, and the four rooms it could not have known about

`tools/fixtures/t/tools_py_ban_scan.sh` enforces this tree's ban on Python under `tools/`. It pruned
two directories by name, with its reason written beside them: *tools/.cache (HAWM Android SDK) and
tools/.build stay gitignored; counting them would false-RED the living tree on Framework.*

So this guard had already met the fault and paid for it, in the direction a guard can least afford:
a red on every ship, for a file no clone holds. What a list of two names cannot cover is the room
nobody had opened yet. **Git's own rules disown six paths under `tools/`** -- `tools/.build/`,
`tools/.cache/`, `tools/bin/`, `tools/glow/`, `tools/fixtures/.forge_view_bundle/`, and
`tools/fixtures/session_logs_archive/_sandbox/` -- and the prune named two.

**Proven on metal rather than argued.** A file planted at `tools/bin/probe.py`, a room `.gitignore`
names on its own line 294:

```
$ sh tools/fixtures/t/tools_py_ban_scan.sh        # the elder spelling
TOOLS_PY_BAD
tools/bin/probe.py
$ sh tools/fixtures/t/tools_py_ban_scan.sh        # asking git
TOOLS_PY_FILTER=git
TOOLS_PY_OK
```

Four of the six rooms stand absent on this disk today, so the fault was latent rather than live --
which is the honest shape of it, and the reason the repair is cheap now and expensive the morning a
build output lands there.

**The fallback stays, and says which branch ran.** That script resolves its root by an upward walk
that is deliberately git-free, so a copy of it runs in a pen outside any repository, and a copy that
read every path as ignored would refuse nothing. So the spelled prune remains as the no-git branch,
and `TOOLS_PY_FILTER=git|spelled` is printed -- a silent fallback is the same shape of fault this
repair closes.

## Two rules refused, and the refusals are the interesting part

**A `.` walk sitting after a `cd` is a walk of somewhere else.** Seven stand, and they split three
ways: `cd "$ROOT"` in `glow_desk_reach_scan.sh` and `radiant_select_wave.sh` lands on the repository
root, so `.` genuinely is the tree; `cd "$CORPUS"` in `one_title_scan.sh` and
`line_length_census_scan.sh`, and `cd "$SRC"` in both cellar exports, land in a pen, so `.` is not.

The first draft reclassified every cd-relocated walk out of the gated number, and that **dropped
three real findings.** The obvious patch -- treat a variable named `ROOT` as the root -- is the same
claim-about-remembered-names this whole reading exists to retire, one layer up. So neither rule
shipped: all seven stay counted, all seven are printed under `cd_relocated`, and **four of the
twenty-eight are inert members of the gated number**, said here rather than hidden. A lane working
the class down knows which four it can never bring to zero.

**A variable root is a named gap, not a guess.** Sixty-three sites walk a root held in a variable.
Resolving one needs the shell's own state at that line, and guessing in either direction is worse
than saying so: a wrong *tree* reading inflates a gated number, and a wrong *pen* reading hides a
real walk. They are counted and each one named.

## What the control proves

Thirty-two behaviors on real git repositories in a throwaway pen, every refusal planted and then
lifted, since a refusal proven only in the passing direction cannot be told from a bypass. The two
that matter most:

- **The cure, both ways from the same bytes.** One walk of `tools`, counted; the same walk with a
  `git check-ignore` guard in the loop, lifted. One `.gitignore` line stands between the exposure
  legs reading zero and one.
- **Two mutations, each asserted to bite.** Drop the command-position anchor and the sentence *a
  reader will find tools useful here* is counted as a walk of `tools`. Stop looking for
  `check-ignore` and a cured file reads unfiltered. A check nobody has watched fail is a check
  nobody has proven.

And the instrument reads its own footing: without git it prints `verdict=no_git` and declines, rather
than calling every walk in the tree clean. An empty corpus refuses the same way. A meter that opened
nothing prints a beautiful ceiling.

## What this does not reach

**Whether an ignored path would move a published number.** This counts walks that can reach one. Two
of the ten probed by hand at `%722` actually moved, so the roster is a work list rather than a charge
sheet, and the ranking inside it belongs to whichever lane owns each guard.

**Two walks sharing one line.** The grep answers per line, so a line carrying two `find` calls counts
once. No living site does; the reading errs downward, and saying which way it errs is what lets a
reader trust it in either direction.

**The sixty-three variable roots**, named above. Closing them wants a shell that can say where a
variable pointed at that line, which is a different instrument on a different lap.

**Anything outside `tools/`.** A walk in a module's own build script reads the same disk. This lap
took the room where guards live, because a guard reading its own scratch is the shape that reddens a
fleet.
