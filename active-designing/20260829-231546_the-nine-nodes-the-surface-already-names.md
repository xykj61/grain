## The ruling, in one paragraph

A semantic node describes a presentable unit. The surface today presents exactly one frame and
up to eight declared lines, so the snapshot's capacity is **`1 + max_declared_lines`, nine
seats** -- a derivation over the seated line ceiling, keeping the tree's habit of deriving every
figure from a seated source. One uniform node shape carries three things. A **closed role**
(`frame` or `textLine` today) grows only when the surface grows, the way the input-kind table
grows. A **label of the seated nib width** owns 128 inline bytes with a count of one through
128: the root node carries the frame's own at-nib identity, and a line node carries its
already-rendered line bytes, one through forty fitting inside. A **cell rect in grid units**
spans row zero through seven, column start zero through thirty-nine, and cell count one through
forty. The first seat carries role, label, and rect alone; interactive nodes arrive with their
own seated table when widgets do. The snapshot regenerates whole from current state into reused
scratch, `AccessibilityTooLarge` answers past the ceiling with the last whole snapshot still
available (the decision table's own words), and Surf and Skate are compile-time aliases over
the type, exactly as with every sibling.
