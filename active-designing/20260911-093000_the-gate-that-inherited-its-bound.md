# The gate that inherited its bound

**Stamp:** `20260911.093000`
**Language:** EN
**Style:** Gauge, Field setting (see `../context/GAUGE_STYLE.md`)
**Voice:** Kyri
**Status:** Living -- **Room:** checkable (every claim below is a reading the guard publishes)
**Ledger:** `construction/REDS.md`, the row of `20260911.093000` (cited by stamp until the anointed spine binds its number -- `.claude/rules/derived-spine.md` rule 4)
**Instrument:** `tools/fixtures/l/law_tool_citation_scan.sh` under `tools/l/law_tool_citation_witness.rish`

A guard built yesterday walls every `tools/` path the law room prints, at zero. Its header argues
the wall this way: a law page naming a guard is making a promise about a file that already exists.
Read that sentence again with the word `tools/` taken out, and it still holds. A law page naming a
foundation, a spec, a context guide or a design essay makes the same promise about the same kind
of file, for the same reason.

The room prints 128 such paths into eleven other rooms, and until this morning nothing read one.

## What the measurement found, and what it then became

The first reading was taken on `20260910`, and it found a class: 99 `tools/` paths, 50 of them
written as bare backticked names, which the link guard reads past. That measurement is what made
the gate worth building, and it is also what set the gate's edge. The scope came from the search,
rather than from the argument.

This is a shape worth naming, because it is cheap to make and quiet once made. A defect is found
by a particular query. The query has a scope. The repair is scoped to what the query saw. And the
page then reads as though the whole subject were covered, since the header states a general
principle and the code applies it to one class.

**A gate inherits the bound of the measurement that discovered it.** The tell is a header whose
argument is broader than its own predicate.

## What was standing in the unread class

Two stale citations, both of the same shape. `20260715-163000_radiant-style-self-critique-benediction-vocabulary-ornament.md`
and `20260717-181715_tame-slc-rye-audit-ledger.md` folded from flat `active-designing/` onto
`active-designing/yonder/date/`, as the fold law asks. Three law pages and one twin kept the
pre-fold paths.

The sharpest of the four is on one line of `.claude/rules/tame-guidance.md`, which reads:

```
**Ledger:** `active-designing/20260717-181715_...` - **Brief:** `active-designing/date/20260707/20260707-164612_...`
```

The Brief citation was repointed. The Ledger citation, four words to its left, was not. A hand
swept the line and repaired the half it was looking at. That is what an unread class looks like
from inside: correct work, beside identical work still waiting for its instrument.

## The repair, and the one thing it declines to do

`room_cited_untracked` is a second reading with its own wall at zero, over every non-`tools/` path
the law room prints, normalized to the root.

It is a **second** reading rather than a wider first one, because `cited_bare` and `cited_runners`
are measured against `cited_paths`. Fold room paths into that total and both become ratios against
a different denominator, and a merged number can be improved by moving a citation between the
classes. The ASCII comment meter learned the same lesson at its trailing reading two days ago.

Three classes are read past, and **none of them is a typed list of exceptions**:

| Class | Why it is honest | How it is decided |
|---|---|---|
| absolute path | `/etc/nixos/configuration.nix` names the host, and `declared-host-config.md` exists to say the tree's file is elsewhere | the token starts with `/` |
| placeholder | `stamp-and-name.md` **requires** an illustration to use one, under its own heading *Illustrate with placeholders, cite only what exists* | `YYYY`, `HHMMSS`, `MMDD`, `sprig`, `NNN` |
| gitignored | this tree's `.gitignore` denies the root with `/*` and allows each project room back by name, so the question *is this a room the repository keeps* already has an answer on disk | `git check-ignore` |

The third is the one worth dwelling on. A typed exception roster is the thing `%706` and yesterday's
alias-group reading both booked: a list that cannot grow, answering a question about a population
that does. Here the tree's own deny-by-default `.gitignore` does the work. `.lap/commit-msg.txt`
and `.gnupg-rye/gpg.sh` answer yes; a missing page under `foundations/`, `docs/` or `context/`
answers no and reds. One test does the whole job, and it stays true as rooms open.

One illustration survived all three, and it took a **placeholder** rather than an exemption:
`docs/redacted/a-note.md` in `ascii-first.md` became `docs/<subroom>/<page>.md`. Applying the
tree's seated law was cheaper than writing an exception to it, and the gate now stands at zero
with its survivor list empty.

**An angle-bracket form is handled by the token shape alone**, and the control proves that rather
than the header asserting it. The token shape carries no `<`, so `docs/<subroom>/<page>.md` is never collected in
the first place. A filter for it would read as a working clause while idle.

## What is proven, and what is not

Sixty-seven control legs on real git repositories in a throwaway pen, every plant counted while it
stood and read back to zero once lifted. **Five mutations of the room reading were bitten**: drop
the `check-ignore` test, drop the absolute filter, drop the placeholder filter, drop the climb
strip, or take the room gate off the verdict, and three to four legs fall each time.

The leg **count** is published and pinned by the witness, because `control_failures=0` reads
exactly the same whether a leg passed or was deleted.

One question it leaves alone: whether a relative citation climbs the right number of levels. A leading
`../` run is stripped and the remainder read from the root, since the room writes both
`../../foundations/x.md` and `../foundations/x.md` for the same file. The link guard owns the
climb; this one owns existence.

It leaves aside, too, whether a named page says what the citing law claims it says. That is the judged
half of Truth, and it belongs to a reader.

## What a reader might carry from here

When a guard's header states a principle, read the predicate underneath it and ask whether the two
have the same edge. Where they part, the difference is the unread class, and it is usually the
size of the search that found the first one.

May every gate reach as far as the sentence that justifies it.
