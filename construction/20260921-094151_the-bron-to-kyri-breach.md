## The scope, declared before the first file moved

This breach completes a molt that began on `20260810` and stopped halfway. On that day the notation
was renamed **Bron** to **Kyri** on Keaton's word, and new logs began writing `.kyri` -- but the
elder `.bron` files were left on disk, and the word "Bron" stayed in the tree's prose, tools, and
folder names. This breach finishes the molt:

1. **Every `.bron` file becomes `.kyri`** -- the 2,926 files, renamed, byte for byte unchanged.
2. **`bron-resins/` becomes `kyri-resins/`** -- the folder, its `manifest.bron`, and its resins.
3. **`template-manifest.bron` becomes `template-manifest.kyri`** -- the root manifest, and every
   reference to it.
4. **Every "Bron" reference becomes "Kyri"** -- in prose, in tool names, in the pipeline
   (`Brix -> Bron -> Mantra` becomes `Brix -> Kyri -> Mantra`), and in the notation's own name.

## The reason

The notation has one name now, and a tree that keeps two names for one thing is a tree that will
quietly drift. The elder name was kept out of accrete-never-break courtesy; the courtesy has
outlived its need, and Keaton's word closes it.

## The far-side shape

No `.bron` file remains. No "Bron" reference remains. The notation is named **Kyri** everywhere --
the same word that names the voice, doing its second job, exactly as `context/KYRI.md` already
describes.

## The six promises, kept

1. **Declared first** -- this page, before the first `git mv`.
2. **Every byte preserved** -- rename and re-point, never rewrite.
3. **Finished inside scope** -- every reference turned in the same motion.
4. **Witnessed both sides** -- `git grep` for `.bron` and "Bron" reads zero after.
5. **Measurably better** -- 2,926 files and the word "Bron" counted before, zero after.
6. **Stands alone** -- its own commits, nothing riding along.
