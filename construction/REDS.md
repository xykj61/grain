## Why this file, and what belongs in it

Own-reds-immediately has been a house law for a long time, and it worked: reds were named the moment they were found, out loud, without excuse. What the law never said is **where**. So the ones that happened to land inside a witness header or a spec erratum survived, and the ones that happened in a sentence did not.

Three fields per row, because a red with fewer teaches nothing:

- **What went wrong** -- stated plainly, no softening.
- **What caught it** -- a compiler, a stopwatch, a guard, a second look. Never "I noticed."
- **What it taught** -- the transferable rule, which is the only part that outlives the incident.

A red enters this ledger when it is found. Rows are never edited or removed; a later correction accretes as a new row pointing back.

## What the pattern says

Read down the *what caught it* column and almost nothing was caught by thinking harder. A compiler, a stopwatch, a file-type check, a guard's first run, seven witnesses at once, a pack catching its own author. **The machine caught nineteen of twenty.**

That is not a complaint about judgment; it is the argument for the whole apparatus. Witnesses exist because the author is the last person able to see their own gap, and this column is twenty lines of evidence for that claim rather than one more assertion of it.

Read down the *what it taught* column and four rules recur: **measure before claiming**, **scope before shipping**, **fixture rather than remember**, and **narrow the objection**. Those four have paid for themselves repeatedly in a single sitting.

**REDS %177 (`20260824.025704`) -- the tree printed a command that bash cannot run.** *What went wrong:* `tools/l/launch-claude-season.rish` prints the unattended-loop recipe -- long single-quoted shell prompts a hand copies into an outer terminal. Inside a single-quoted shell string a literal apostrophe has to be written `''`, and **one of them was written as a lone `'`**, in the words *the linker's own search path*, added by the lap that seated the ask-the-system discipline. A lone apostrophe closes the string, so every character after it falls out of quoting, and the first later parenthesis -- `(round-set, quest, journey, equinox, season)` -- reached bash as syntax. Both printed launch lines died with ``syntax error near unexpected token `('``. **The season loop could not start at all**, and the paste looked at fault when the tree was. *What caught it:* Keaton pasted the line and read the error, then asked whether it was fixed -- and the root was found by reproducing the parse rather than reasoning about the text: writing the pasted command to a file, `bash -n` on it, then collapsing one `''` to `'` and watching the identical error appear. *What it taught:* **a string a tool prints for a hand to run is code, and until something parses it, it is untested code.** Every guard in the roster read files the tree executes; nothing read the one thing a person was told to execute. The class is wider than quoting: any generated command line -- install lines on the operator card, a recipe, a copyable one-liner -- carries it. *Repaired:* both `say` lines escaped to `linker''s`, and all six printed runnable lines now parse. Prevention seated as the 36th standing guard: [`tools/l/loop_prompt_parse_witness.rish`](../tools/l/loop_prompt_parse_witness.rish) over [`tools/fixtures/loop_prompt_parse_scan.sh`](../tools/fixtures/loop_prompt_parse_scan.sh), which runs the recipe tool and `bash -n`s every printed line the reader is told to run, gated at zero, with narration left free. Proven both ways by [`tools/fixtures/loop_prompt_parse_control.sh`](../tools/fixtures/loop_prompt_parse_control.sh) -- eight cases in a temporary pen: the lone apostrophe refused and its line named, a correctly doubled one passed, prose apostrophes left alone, the outer loop's own line measured beside the jail elder, and an empty or absent printout told apart from a failing one.
