**REDS %226 (`20260825.183029`) -- two guards spoke one host's dialect and the second host heard silence.** *What went wrong:* the negation regex in [`../tools/fixtures/prose_register_scan.sh`](../../tools/fixtures/prose_register_scan.sh) used gawk's `\<` word boundary, which BSD awk reads as matching nothing -- so on the tree's first macOS bench every file measured 0% negative, the Door gate passed trivially, and `qa_report_card.sh`, which lifts `measure()` from the same file, silently inflated every Register reading to 100. Beside it, [`../tools/p/parity-selftest.rish`](../../tools/p/parity-selftest.rish) tampered its shadow with GNU `sed -i`, which BSD sed reads as a backup suffix, so the selftest died before its first assertion. *What caught it:* the register witness's own control leg -- the planted refusal-led text refused to read high, exactly what a control is for -- on the first macOS run, `20260825.172530`; the sed failure fell out of the same lap's witness sweep. *What it taught:* **a guard is only as portable as its narrowest dialect, and a control leg is what turns a silent zero into a loud refusal** -- the counsel host had already hit the same boundary in mawk and re-expressed the word list with POSIX classes, and that re-expression reproduced every reading exactly, so the fix was already proven before it landed. *Repaired:* the `neg` pattern in the scan's `measure()` function now wears POSIX boundary classes (`(^|[^a-z0-9_])...($|[^a-z0-9_])`), identical in boolean per-sentence effect on gawk and true on BSD awk and mawk; the selftest's tamper line writes through the inode (`sed > tmp && cat tmp > file`), the exec-bit rule's own shape. Proven on metal on the macOS bench: the register control reads `control_verdict=ok` with the reading discriminating, the full witness GREEN, the Door roster reading real shares (every page inside 20%), the card's Register honest (a 100 fell to 73), and parity-selftest GREEN end to end. The falsifier stands where it belongs: the pier's next roster run shows the Door numbers unchanged under gawk. CLOSED.
