**REDS %335 (`20260828.232444`) -- the seam's nil guards were dead on arrival: a non-optional return made every assert after it unreachable in law.** *What went wrong:* `tools/rye/objc_seam.rye` declared `SendId`, `SendClassId`, `SendClassStr`, and `SendWindowInit` returning bare `Id`, a pointer type the language promises is never null, and every macOS probe guarded the answer with an assert on the pointer's integer value. A nil answer lands in a non-optional pointer, which is illegal behavior BEFORE the assert runs -- the compiler marks such returns nonnull and is licensed to fold the guard to true -- so the checks written to catch nil structurally could not fire, on selectors that honestly answer nil (`initWithContentRect:`, `initWithFrame:`, `stringWithUTF8String:`, `currentContext`). Two smaller drifts of the same class stood beside it: `setActivationPolicy:` verified as `B@:q` yet sent through a void-returning type -- the seam's one gate not covering the seam's one unsafe operation -- and the read-back verify of an added `drawRect:` comparing the declared string against itself, since `class_addMethod` stores it verbatim; a gate that could not gate. *What caught it:* an adversarial review fanned out over the LOCA rung's diff -- three lenses, a refuter on every finding -- confirmed these three and refuted eight others; the green runs could not have caught them, since Debug builds materialize the compare, nil never arrived, and a tautological check is green by construction. *What it taught:* **a guard the type system makes vacuous reads exactly like a guard that holds** -- the optional belongs in the send type wherever a selector can honestly answer nothing, so the check is the `orelse` at the call rather than a dead assert after it; and the independent authority for an added selector's encoding is the SUPERCLASS's compiled record, read before the add, never the runtime's echo of the caller's own string. *Repaired (`20260828.232444`):* the four send types return optional and every caller unwraps with a named error; `SendIdI64` returns the bool its verified encoding declares, discarded aloud with `_ =`; the view-class probe verifies `drawRect:` against NSView's own record before the add; `send` gained the comptime asserts its inward twin `imp` already carried; and every event-pump turn now runs inside its own autorelease pool, so the loop a real backend stands in is bounded in memory as well as in turns. All three probes GREEN on metal after the repair; the view probe's prove-red leg still exits 134.
