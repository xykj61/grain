**REDS %140 (`20260822.125218`) -- the widening meter read only names opening in lowercase, so every type a shared body reached priced at zero, and the fold queue was ordered on half a cost.** *What went wrong:* [`../tools/fixtures/ladder_reach_visibility_scan.sh`](../../tools/fixtures/ladder_reach_visibility_scan.sh) prices a fold by reading the shared body, extracting every identifier it reaches unqualified, and joining that list against each rung's own top-level declarations to count how many stand private. Both halves of that join used the character class `[a-z_]` -- the body's identifier grep read `[a-z_][a-zA-Z0-9_]*`, and the declaration reader matched `/^(pub )?(fn|const) [a-z_]/`. Zig type names are capitalized by convention and this ladder follows it without exception, so **no type was ever seen on either side**. A control proved the blindness whole rather than partial: two generated rungs sharing one body over a private `Ledger` reported `reached=0 widens=0`, the meter answering not that the cost was zero but that it had found nothing to look at. On the living ladder the row that led the fold queue, `judge_outcome`, priced at **37** widenings -- all of them free import bindings of `carry`, which the harness already imports -- while its true cost is **74**: the other thirty-seven publish a private `Finished` struct as rung API in each of the thirty-seven folding rungs. `may_pass` was under-priced the same way, 96 against 101. *What caught it:* reading a candidate body by hand before lifting it, and noticing that the parameter type `Finished` stood `const` rather than `pub const` in all thirty-seven rungs while the meter that had just read that body reported nothing to widen. *What it taught:* **a meter that reads identifiers must name the whole identifier grammar it is reading, and a language's own naming convention is part of that grammar.** The compiler was a real backstop -- a lift reaching a private type simply refuses to build -- yet the backstop fires *after* the queue has already been ordered, and the ordering is the decision the meter exists to inform. A blindness that costs nothing on the lap it fires still costs the choice it silently made.
