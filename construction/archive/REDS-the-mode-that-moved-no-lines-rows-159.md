**REDS %159 (`20260823.025333`) -- a rewrite moved a temporary over each original, and thirty-nine exec bits went with it.** *What went wrong:* the repoint of `REDS %155` rewrote 116 path literals across 58 tracked tool sources by writing each file to a temporary and moving the temporary over the original. `mv` carries the temporary's mode rather than the original's, so the same commit dropped mode `100755` to `100644` on **thirty-nine** tracked files. Nothing in the diff said so: a mode change moves no lines, so `git show --stat` reported `1 file changed, 0 insertions(+), 0 deletions(-)` and the round read as a clean repoint. All twenty-three rostered guards stayed green, because all twenty-three read lines. One of the thirty-nine was `tools/ag/agent-jail.sh`, which the unattended loop invokes as `./tools/ag/agent-jail.sh`; the loop answered `Permission denied` once every twenty seconds through the night and the season stopped there. *What caught it:* Keaton, reading the terminal, and repairing it with `chmod +x` by hand. *What it taught:* **a mode is tracked content, and every meter this tree owns reads lines.** The tree already knew the safe shape and had written it in the right place -- `tools/fixtures/dated_path_repoint_scan.sh` rewrites with `cat "$f.dpr" > "$f"` and preserves every mode -- yet the knowledge lived in one script rather than in a rule or a guard, so the next rewrite reached for `mv` and no meter could see the difference. This is the third firing of one lantern in three laps: `REDS %150`, `REDS %156`, and now a whole class of tracked content that **no** rostered guard reads at all.

**REDS %159 CLOSED (`20260823.025333`) -- a script the tree tells you to run is a script you can run.** *The repair, on metal:* all thirty-nine modes restored in the working tree and the index (`chmod +x` and `git update-index --chmod=+x`), returning each file to the `100755` it carried before the repoint. The loom is [`../tools/e/exec_bit_witness.rish`](../../tools/e/exec_bit_witness.rish) over [`../tools/fixtures/exec_bit_scan.sh`](../../tools/fixtures/exec_bit_scan.sh), which reads modes and nothing else. Two readings gate at zero: every tracked file carrying a shebang that a **living** tracked file invokes directly -- `./path` in command position -- holds index mode `100755` (**18** files stand in that set), and every tracked file's on-disk exec bit agrees with its index mode (**0** of 13,650 disagree), so a drift is seen in the working tree where repair costs one `chmod` rather than discovered in history. A path with its interpreter named ahead of it passes free, which is why the **58** uninvoked fixture scans sit in a ratchet under a ceiling that only falls rather than in the gate: every witness runs them as `run ["sh" "tools/fixtures/..."]`. Dated testimony gates nothing, keeping every reference it ever wrote. [`../tools/fixtures/exec_bit_control.sh`](../../tools/fixtures/exec_bit_control.sh) builds real git repositories in a temporary pen and proves **sixteen** behaviors -- five refusals bitten and eleven honest readings left free, the ratchet ceiling proven from **both** sides by planting fifty-nine files against a ceiling of fifty-eight, so no override exists and none is wanted. The shape is written as law in [`../.claude/rules/exec-bit.md`](../../.claude/rules/exec-bit.md): rewrite in place with `cat "$tmp" > "$f"`, never `mv "$tmp" "$f"`. The guard stands as the roster's twenty-fourth row, and the first reading of a kind of content the roster could not see.
