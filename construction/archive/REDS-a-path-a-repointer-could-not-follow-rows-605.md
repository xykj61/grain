**REDS %605 (`20260908.020050`) -- a fold moved a file, and the one path assembled from fragments stayed behind.** *What went wrong:* `tools/fixtures/s/shed_census_scan.sh` builds its orphan-control path out of four shell variables -- `ORPHAN_DIR`, `ORPHAN_STAMP`, `ORPHAN_STEM` -- deliberately, so the scan file never holds the contiguous string it is testing for absence. When `tools/` folded into letter rooms on `20260823.144100`, `tools/t/tool_path_repoint.rish` carried every literal path across, and `ORPHAN_DIR` stayed `tools/fixtures` while the file moved to `tools/fixtures/2/`. The scan then answered `CONTROL=untracked` about a file `git ls-files` lists, and exited 1. **The proof stands in the same file:** `CITED` two lines above names the same folded directory as a literal, was repointed, and reads `tools/fixtures/2/` today. One file, one fold, two paths, and the only difference is whether the string was contiguous -- which is exactly the property the assembly exists to destroy. *What caught it:* `season_leaf_choir`, sixteen days later, and only because a lap ran the cadence red it had recorded rather than reading the verdict. The chain was four deep and every layer reported honestly: `shed_census` said `detail_path=` and named the stale path, `instrument_suite` counted it `limb_shed_census=RED detail=exit_nonzero`, and seven equinox leaves said `living scan must exit 0`. Nothing was hidden; nobody had walked down. *What it taught:* **a repointer reads text, so a path a program computes is a path no repointer can follow.** A fixture hiding a literal to defeat a grep has, by construction, also hidden it from every tool that maintains paths -- and the hiding is usually load-bearing, so the answer is not to stop assembling but to keep the fold-fragile part, the directory, on its own line where a hand repairing a fold finds it by eye. *Repaired:* `ORPHAN_DIR=tools/fixtures/2`, with the reason written beside it. `shed_census` and `thing_not_name` are GREEN, `instrument_suite` reads `pass=10 fail=0`, and the choir fell **7 red to 5**. **BOOKED** -- this defect's one instance stands repaired and proven on metal; the general repair, a meter reading tracked fixtures for a path built from variables rather than written whole, is a lap of its own. The five leaves still red are two other roots and want their own rows: e133 gates on `want_bare_date_10` where the tree reads 9 bare dates and 2 full stamps, and e117/e118 are unread.
