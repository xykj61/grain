# DIFFUSER -- the fourth angle's own open crux, answered by a census

**Stamp:** `20261001.193541`
**Status:** Shelved whole -- the-writer-sheds

## Account

The fourth-angle whitepaper thread left one crux open: whether a content-defined
resin split is worth building, and what a real Mantra revision caller's edit traffic
would look like. This lap read the question to its root rather than its chunker: a
census of every storage caller this tree has written -- the fourteen
`tablecloth.store_artifact` sites, the spool-backed large-artifact catalog
(`pond/apps/spool_cloth.rye`), and Tilak's leaf-append log
(`mantra/recall_beaded.rye` and its two production callers in `comlink/`) -- shows
every one keeps a name bound to the one set of bytes it was first given. No caller
in this tree today asks a stored artifact's name to hold still while its bytes
change, which is exactly the traffic shape content-defined splitting exists to serve.

[`active-designing/date/20261001/20261001-193541_no-caller-wants-a-mutable-identity.md`](../../../../active-designing/date/20261001/20261001-193541_no-caller-wants-a-mutable-identity.md),

and fourth-angle ladders both read closed, and the honest next Mantra crux -- a
module that needs one name's identity to survive an edit -- is named rather than
built.
