# REDS -- the fold that moved depth (row %169)

*Folded from [`../REDS.md`](../REDS.md) on `20260823.161500`, CLOSED, as row %172 carried the living pin past its 24,576-byte bound.*

**REDS %169 (`20260823.144100`) -- a repointer moves text, and a fold moves depth; everything keyed on depth went quiet.** *What went wrong:* the fold repointed 8,503 path literals and left four other kinds of reference untouched, each of which fails **silently** rather than loudly. A shell glob -- `for p in tools/*.rish`, `grep -rIl ... tools/*_witness.rish` -- matched every file while the room was flat and matched **nothing** the moment it folded. `find tools -maxdepth 1 -name 'caravan_*_witness.rish'` did the same. Thirty-three scripts computed the repository root as `$(dirname "$0")/..`, which had been true at `tools/x.sh` and became `tools/` at `tools/g/x.sh`. And two tracked **symlinks** pointed at flat tools paths, which no text rewriter can see because a symlink's target is not text in any file. *What caught it:* `tracked_link` caught the symlinks on the roster run. The rest were caught by **hand-running three witnesses** -- the roster stands at 30 guards against roughly 1,800 witnesses, so nothing on it would have looked. *The worst of them, and the one worth the row:* `docs-geode/libraries/README.md` regenerated with a witness count of **zero for all thirty-eight rooms**, and `geode_libraries_witness` passed **green**, because the page and the fresh render it is compared against are computed by the same generator -- and the generator's glob was broken. The page's own header warns that *a confident wrong zero is worse than no number at all*. *What it taught:* **a freshness guard proves a page agrees with its generator, never that the generator is right** -- so a generated page needs at least one reading a human or a second tool would notice going to zero. And the general form, which is REDS %166's sentence at a second surface: **a fold changes depth, so every rule keyed on depth -- a glob, a `maxdepth`, a `dirname $0` climb, an anchored ignore pattern -- is a rule the fold silently retires.** Repaired: three scans now find recursively (with `tools/fixtures/` pruned as instrument), two caravan roster reads take two levels, thirty-three scripts climb one level further, both symlinks retarget, and `tools/co/corpus_twin_verbose.sh` computes a tool's room the way the resolver does.
