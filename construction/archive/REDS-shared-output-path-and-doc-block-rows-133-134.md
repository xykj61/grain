**REDS %133 (`20260822.092442`) -- eighty witnesses built one binary at one path, so any witness run beside the choir reddened a tree that was green.** *What went wrong:* every per-rung Caravan witness that needs the read helper built `caravan/read.rye` to the literal path `caravan/bin/read` -- eighty witnesses, two hundred and eight references. The per-rung binaries were already unique, one per rung; the shared helper was the single exception. Two processes writing one output path race: one truncates the file while the other links it, and `rye build` answers with a failure that reads exactly like a broken rung. This lap ran three witnesses beside a singing choir to get faster feedback on a fold, and watched `caravan_reweigh_witness.rish` and `caravan_reopen_witness.rish` both go RED against a tree where each was GREEN when run alone. `reopen.rye` had not been touched at all that lap, which is the tell. *What caught it:* the second RED disagreeing with the first reading. One RED on a file the lap had edited is a fold to re-examine; a second RED on a file the lap never opened is a meter to distrust, so the two were re-run alone and both answered GREEN. Reading `tools/ca/caravan_reweigh_witness.rish` line 86 found the shared literal, and `grep -c` found the same literal in seventy-nine siblings. *What it taught:* **a false RED is worse than a missed one, because it teaches a bench that a green tree can look red and the next real RED is met with a shrug.** The Radiant pass playbook already writes this down for blocking witnesses -- a gate that reds on valid input teaches the bench to route around it -- and the same sentence holds for a shared output path. A meter must be a function of the tree alone, and a path two runs can both hold makes it a function of the schedule as well. **This is the same lantern REDS %92 lit, one step further along.** That row taught each witness to *build* its reader rather than borrow one already sitting on disk, and every one of the eighty carries the comment saying so -- yet they all built it to the same name, so the borrowing came back through the output path instead of the input. Owning the build and owning the file it lands in are two halves of one invariant, and only the first half was written down.

**REDS %133 CLOSED (`20260822.092442`) -- every witness builds its read helper to its own path, so two different witnesses never meet on one file.** *The repair, on metal:* each of the eighty witnesses now builds to `caravan/bin/<rung>_read`, named from its own filename -- `caravan/bin/abate_read`, `caravan/bin/reweigh_read`, and so on through `caravan/bin/read_read` for the read rung's own witness. Two hundred and eight references moved, and `caravan/bin/` is gitignored, so nothing but the build tree changed. Proven by running two different witnesses concurrently, the exact pair that raced: before the change they contend for one file, after it each holds its own. **The residue is named rather than claimed closed:** running *the same* witness twice at once still races on that rung's own binary, and no naming scheme can fix that, since the two runs genuinely want the same output. The invariant the tree now relies on is that the choir sings each witness once and serially, so a bench running one witness beside it is safe while a bench running the *same* one is not. That remainder is a ratchet on the bench's habit rather than a defect in the meter.

**REDS %134 (`20260822.094338`) -- a doc block described one function and bound to another, so two declarations carried a wrong claim inside a green commit.** *What went wrong:* the `seat_note` lift wrote its twenty-four-line doc block into `caravan/ladder_checks.rye` above `pub fn read_words` while inserting `pub fn seat_note` below it. Zig binds a doc comment to the next declaration, so `read_words` -- which reads a word list -- was documented as *"Writes one note for a dependent"*, complete with the fold arithmetic of a family it has nothing to do with, and `seat_note` stood with no documentation at all. Both wrong claims rode a signed commit that ran the whole choir green, because every witness on the ladder reads behavior and none reads prose for the declaration it lands on. *What caught it:* reading the harness by hand while pricing the next fold head -- the twelfth lift of this arc, and the first to look up at the neighborhood it was writing into. *What it taught:* a lift moves a body and a doc block as one gesture and the tree only ever checked the body. A doc block that carries the widening meter's own `family=X` citation already states which declaration it documents, so the binding is a name against a name rather than a reading of prose -- checkable, and now checked.

**REDS %134 CLOSED (`20260822.094338`) -- the fold's own citation names its declaration, and the harness is held to it.** *The repair, on metal:* the twenty-four-line block moved down to sit directly above `pub fn seat_note`, leaving `read_words` its own one-line summary. [`tools/fixtures/ladder_doc_attachment_scan.sh`](../../tools/fixtures/ladder_doc_attachment_scan.sh) then reads every doc block in the harness that cites `family=X` -- seven of them, the citation wrapping across lines where the prose wrapped -- and refuses any block whose family differs from the `pub fn` beneath it, with `verdict=doc_names_another_declaration`. [`tools/l/ladder_doc_attachment_witness.rish`](../../tools/l/ladder_doc_attachment_witness.rish) proves three legs on generated controls: a block citing `seat_note` above `pub fn read_words` is refused in the exact shape the red wore, a harness carrying no citation refuses rather than blessing its own blindness, and a correctly attached block is welcomed -- because a gate that reds on valid input teaches a bench to route around it. GREEN on metal at `cited=7 docs_adrift=0`. **The residue is named rather than papered over:** the guard binds only blocks carrying a `family=` citation, so a doc block written without one is checked by a reader alone. Every fold of this arc writes the citation, which is what makes the check worth its weight; a fold that stops writing it stops being seen.
