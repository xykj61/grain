**REDS %181 (`20260824.045445`) -- the round that widened the dated rule cited two files that exist nowhere.** *What went wrong:* the REDS %180 repair added Zig unit cases to `day_from_log_fname` and a ledger row describing them, and both reached for a plausible sprigless name rather than a real one -- a `YYYYMMDD-HHMMSS.bron` and a `YYYYMMDD-HHMMSS.kyri`, written out in full digits, naming no file in this tree. **This row cannot quote them.** Writing the two names here would create the citations a second time, inside the row explaining them, and the census would count them again -- which is exactly what happened on the first draft of this row, and is why the digits above are placeholders. A stamp with an extension after it is a **citation** to every reader and to `tools/fixtures/dated_path_scan.sh`, which reads exactly that shape wherever it appears -- so the ledger row acquired one lost reference and the census rose from 187 to 188. *What caught it:* the roster, run **after** `git add` (REDS %174). `dated_path` alone answered red, `refs_lost=188 lost_ceiling=187 under_ceiling=no`, and the two new lines fell straight out of a diff of the scan's `list` output against a stashed tree. *What it taught:* **the mark law already wrote this warning, one lap earlier, and the warning did not carry.** [`.claude/rules/stamp-and-name.md`](../../.claude/rules/stamp-and-name.md) says *illustrate with placeholders, cite only what exists*, and names the three fabrications the census caught on the day the law was written. Naming a fault is not preventing it; the meter is what prevents it, and the meter is why this cost one re-run instead of a month. The transferable form: **an example is either a placeholder (`YYYYMMDD-HHMMSS_sprig.ext`, letters where digits go) or a real path -- never a realistic-looking third thing**, and that holds in prose, in a ledger row, and inside a test string, since none of the three is invisible to a grep. *Repaired:* both unit cases now name real tracked files -- `20260619-072600.md`, a folded sprigless log, and `20260703-120000.bron`, the fixture this round created -- with a comment saying why the names have to be real; the ledger row drops its invented `.bron`. Measured after: `refs_lost=187`, `under_ceiling=yes`, exactly where it stood. No new guard: `dated_path` already gates this class at a ceiling with no slack, and it did its whole job. CLOSED.
