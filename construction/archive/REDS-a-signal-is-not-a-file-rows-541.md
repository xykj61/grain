# REDS shelf -- a signal is not a file

**Stamp:** `20260907.073406`
**Language:** EN
**Style:** Gauge, Meter setting
**Voice:** Kyri
**Status:** Shelf -- immutable once written; the pin keeps what is open

One row, folded on the lap that repaired it. `%541` is the wound where one-writer-per-checkout ran
out of reach: that law names *a file moving* as the thing to announce, so a lap that touched no peer
file believed it had stayed home -- and then sent a signal to six processes in four other trees. A
signal is not a file, and no rule reached it.

What the row taught, in one line: **a process-name match is not a tree boundary.** Eight ships run
one program name from eight trees on one pier, so the reach of `pkill -f <name>` is the fleet rather
than the lap, and the shell that types the pattern carries the pattern -- so the caller is inside
its own blast radius. The repair replaces the match with a resolution: read each candidate's working
directory, compare it against this tree's physically-resolved root, and refuse everything else out
loud. A kill that misses its target is silent on both sides; a refused call is a line both sides can
read.
