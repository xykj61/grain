**REDS %286 (`20260826.234821`) -- a portability repair reached libc, and the pier that made it links libc for free.** *What went wrong:* `caravan/harvest.rye`'s `sweep_one` moved from `std.os.linux.waitpid` to `std.c.waitpid` on `20260826.225356` to close `%282`. `std.c.waitpid` is an `extern "c"` declaration rather than a syscall, and `rye build` links no libc unless a caller passes `-lc`, so on this Linux pier the build refuses outright: *dependency on libc must be explicitly specified in the build command*, referenced by `sweep_one` and `choose_slot`. macOS links libc into every binary it builds, so the same command on the bench that made the change produced a clean binary and a GREEN witness. Neither of the two witnesses that build `caravan/harvest.rye` carried the flag, because before this change the module needed none. *What caught it:* the standing roster's cold open on this pier -- 70 of 71 green, `caravan_suite` red at `tools/ca/caravan_harvest_witness.rish`, deterministic on a settled tree with `tree_moved=no` and no second session in the checkout. The choir stops at its first red, so the reading also could not say what stood behind it until the flag landed. *What it taught:* **a build flag a host does not need is a flag that host cannot test.** The seam `%282` closed was a kernel named in source; the seam it opened is a kernel reached through a library that one platform links by default and the other does not, and the second is quieter -- the first fabricated a green, this one refuses to build at all, which is the honest failure and still costs a lap to find. The tree already knew the answer and had written it down five times: `grep -l -- '-lc' tools/ca/*.rish` read five witnesses before this lap -- `caravan_subscribe_poll_service.rish`, `caravan_subscribe_poll_source_crash.rish`, `caravan_subscribe_poll_mirror_service.rish`, `caravan_subscribe_poll_signal.rish` and `caravan_witness_stop_footgun.rish` -- all passing `-lc` for exactly this reason, because `caravan/subscribe_poll_service.rye` has reached `c.nanosleep` since before the change. The convention existed; the new caller was not joined to it. **That count was written from memory first and read three**, which is the same fault `%284` booked one lap earlier; the number above is what `grep -l` answers. *Repaired:* `tools/ca/caravan_harvest_witness.rish` passes `-lc`, with six lines above it saying why so the next reader does not have to rediscover the platform difference. `caravan/harvest.rye`'s `sweep_one` door comment now names its own requirement, since a module that cannot be built without a flag should say so where a reader meets it rather than only where a witness spells it. `caravan/overtake.rye` builds harvest and needs no flag, measured rather than assumed: it never references `sweep_one`, so the extern is never emitted. `caravan_harvest_witness` GREEN on metal, and the choir behind it re-sung whole. **CLOSED.**
