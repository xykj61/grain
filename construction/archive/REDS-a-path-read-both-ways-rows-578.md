**REDS %578 (`20260907.153124`) -- a scan arguing that sourcing is exact where `cmp -s` is a proxy read the helper's PATH, so a sentence explaining why a control does not import it counted as an import.** *What went wrong:* `tools/fixtures/p/plant_adoption_scan.sh` decided adoption with `grep -q 'tools/fixtures/p/plant\.sh'`, and its own header calls that exact -- *"Sourcing a file is not a proxy. It is exact, it is one grep."* A control landed carrying a paragraph headed **WHY NO PLANT LAW HERE**, saying that its plants are files it authors so there is no claim about somebody else's line to check. Naming the helper in that sentence raised `sourcing` **12 to 13** and red `tools/p/plant_witness.rish`, whose floor asserts the literal `sourcing=12`. *What caught it:* the hot roster pass, on the lap that wrote the sentence -- `plant red 1s`, with `control_verdict=ok` and `behaviors=30` directly above it, so the helper was perfect and only the census had moved. *What it taught:* **a grep for a path reads every mention of it, including the ones that say the opposite.** The header was right that a mention-free reading exists and wrong about which one it had: `cmp -s` is a proxy for a *claim*, and a bare path is a proxy for an *act*. Both are proxies; only the dot command is the act. *Repaired:* the reading is now `^[[:space:]]*\.[[:space:]].*tools/fixtures/p/plant\.sh`, which every one of the twelve real adopters carries and no comment does, and `sourcing` reads 12 again with the witness green. *What is not repaired, and it is the same shape one room over:* `remainder=164` still counts every control that has not imported the law, including the many that plant nothing at all, so the number can never reach zero and nobody can act on it. That is the adoption question its author left for Keaton's word, and this lap did not widen it. **BOOKED.**
