# REDS %499 and %503 -- the test that cannot fail

*Folded from the living pin [`../REDS.md`](../REDS.md) on `20260906.152240`, in the round that
closed both. They are one story told twice: the finding, and the correction of the finding's own
proposed fix, nine hours apart on the same file.*

*The sentence worth carrying forward: **a discriminator has to be shown failing on one side before
it can be believed on the other.** `%499` read the fleet's round-open correctly -- one classifier
answering for two states, ten commits parked between `20260828` and `20260906` that never reached
main -- and then booked a repair that was a tautology. The merge-base of a local line and its
upstream IS the parent of the oldest commit in `upstream..HEAD`, in every state, because everything
in that range is by construction unreachable from upstream. The test was checked where it answered
correctly and never where it would have had to refuse.*

*And the reason the elder fault stood so long is one room over from the fix: **the destructive
branch was the untested one.** Of seventeen control legs, not one planted the diverged state -- the
single branch running `git branch`, `git push xy` and `reset --hard` together on eight live trees
every twenty minutes. A leg count says nothing about which branches its legs reach.*

*What replaced the tautology needs no discriminator at all: attempt the re-derivation the script's
own header already prescribed, and park only when git refuses it. git reads patch-ids, so it drops
a local commit whose rewritten twin already stands upstream -- a thing no shell test can see.*


**REDS %499 (`20260906.140206`) -- the fleet's round-open cannot tell an ordinary lost race from an upstream rewrite, so proven work is parked where nothing reads it.** *What went wrong:* `tools/f/fleet_round_open.sh` step 4 classifies the local line against the anointed order with two tests -- `merge-base --is-ancestor HEAD xy/main` and its reverse. When neither holds it parks the branch on `pier/diverged-<stamp>` and `reset --hard`s to `xy/main`. **Two entirely different states fail both tests.** One is a genuine upstream rewrite, where the ground a line was built on is gone and parking is exactly right. The other is the ordinary outcome of the fleet's own design: a lap commits on base B, a peer pushes on top of B, and `git rebase xy/main` re-derives the local line whole. The script's own header prescribes that re-derivation -- *"an ordinary lost race, answered by re-deriving on the new head"* -- for the push refusal, and prescribes parking for the identical state one step earlier. *What caught it:* this tree opened ahead 1, behind 2, with `HEAD^` equal to the merge-base; the round-open would have parked a commit whose witness, control and ledger row were all proven on metal, and `git rebase xy/main` landed it with two ordinary conflicts. *The measurement, over `refs/heads/pier/diverged-*` on `xy`:* **11 branches, 38 commits, 33 distinct subjects, `20260828` to `20260906`. Twenty-three later reached `main` by a hand re-deriving them; ten never did**, among them `tablecloth: four verdicts nothing ever planted` -- which the operator card carried as an open sibling find while the work sat parked -- and two parked within twenty minutes of this reading. *The discriminator, purely local and needing no reflog:* the merge-base equals the parent of the oldest commit in `xy/main..HEAD` **if and only if** the local line's base still stands in the anointed order, since everything above that parent is local-only and the merge-base is the newest common ancestor. True means an ordinary lost race, re-derivable by rebase; false means the base was rewritten away and the park is correct. *What it taught:* **a classifier that collapses two states answers correctly for one of them and silently mishandles the other, and the safe-looking branch is the one that loses work** -- a park keeps every byte and still costs the tree the whole lap, because a branch nobody reads is `%479`'s dead-letter box with a second drawer. *Not taken:* six ships run this file every round and it belongs to the fleet-friction lane, so the finding is booked with its discriminator rather than applied across a seat boundary. **CLOSED** by `%503`, which found the booked discriminator was a tautology and landed the re-derivation in its place.

**REDS %503 (`20260906.152240`) -- the discriminator booked to tell the fleet's two divergences apart was a test that cannot fail, and the branch it was written for had never been planted.** *What went wrong:* `%499` booked a purely local test for `tools/f/fleet_round_open.sh` step 4's `else` branch -- *the merge-base equals the parent of the oldest commit in `xy/main..HEAD` if and only if the local line's base still stands upstream.* It holds in **both** states, always, and the reason is git's own definition: every commit in `xy/main..HEAD` is by construction unreachable from `xy/main`, so the parent of its oldest member is the newest commit reachable from both, which is exactly what `merge-base` returns. Measured in a throwaway pen on real repositories -- an ordinary lost race and an upstream amend **both** answer *ordinary lost race*, `merge-base == parent-of-oldest` in each. A tautology was booked as the fix for a classifier that could not tell two states apart, and had it shipped, the collapse `%499` named would have stood with a guard's name on it. *What caught it:* reading the booked test against `merge-base`'s definition before writing a line of it, then planting both states rather than trusting the reading. *And why nothing had caught the elder fault:* of the control's seventeen legs, **not one planted the diverged state** -- the single branch holding `git branch`, `git push xy` and `reset --hard` together, run on eight live trees every twenty minutes, was the one branch no leg reached. *What landed:* the re-derivation **is** the discriminator, and it is git's rather than ours -- it reads patch-ids, so it drops a local commit whose rewritten twin already stands upstream, which no shell test can see. The branch now cuts the park ref **first** (step 2's own reasoning: a ref costs nothing and survives a rebase dying mid-flight), attempts `git rebase xy/main`, and on refusal aborts and parks exactly as before; on a clean replay that dropped nothing it releases the park, and on one that dropped a patch it **keeps** the park and says so. Proven on real repositories three ways -- a lost race re-derives with no park left behind, a colliding rewrite parks with the pre-open tip on the ref, a reworded upstream drops the duplicate and keeps the park -- with no rebase corpse in any. Control **17 -> 34 legs**; the elder script fails **8** of the new seventeen, and passes the nine that were already right, since the park keeps every case it was correct for. *What it taught:* **a discriminator has to be shown failing on one side before it can be believed on the other** -- this one was checked only where it answered correctly, and it answers that way everywhere. The deeper habit is the branch, not the test: **the destructive branch was the untested one**, and a control's leg count says nothing about which branches its legs reach. **CLOSED.**
