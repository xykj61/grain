**REDS %496 (`20260906.132818`) -- the quality card's link reading sees one link in seven, so a page whose citations sit where this tree actually writes them reads zero and clears a ceiling it exceeds twenty-five-fold.** *What went wrong:* the Reach reading in `tools/fixtures/q/qa_report_card.sh` computes Flesch-Kincaid and link density in one awk, and that awk holds out four line shapes that carry no sentence -- tables, list items, headings, and lines opening with `**Bold:**`, which its `/^[ \t]*[-*>#]/` rule reads as a bullet. Holding them out of the SENTENCE reading is right; the link count rides in the same pass and went out with them, unremarked -- the one threshold in a 740-line file carrying no comment. Measured over **5,409** tracked Markdown files outside `gratitude/` and `vendor/`: **2,690** links seen, **15,528** held out (9,809 on list, heading or bold-key lines; 5,719 in tables), so the reading sees **14.8%**, and **1,766** files carry links while printing `0 links`. `docs/README.md` -- the worked example inside the card's own index-relief comment -- carries 28 links and reads 5; `docs-geode/wiki/README.md`, whose body is a 14-row table of links, carries 26 and reads 2. *What caught it:* linking eight citations onto `docs-geode/sangha/03-five-primitives.md` and watching the card still print `0 links`, then reading Truth's count of the same file, which said 2 before the edit. **Two readings of one file disagreeing about a countable fact** is what a lap can act on where a plausible grade is not. *What it taught:* **a reading that holds a line out of one question holds it out of every question computed in the same pass** -- the sentence filter and the citation filter were never the same filter, and sharing an awk made them one. The consequence is a meter that prices a citation *in a sentence* as a cost and the identical citation *in a table* as free, which instructs the repair that makes a page worse. And the card's own `declares_index` relief, written to stop an index's link flood from flooring Reach, guards a flood that cannot arrive: an index keeps its links in tables and bullets, which this pass had already dropped. *Repaired:* the whole-page count is read off the file on disk -- never off `$prose_path`, which by then is the reference-block filtered copy, and counting from it would reproduce the blindness -- and printed as `reach_links=<seen> of <total> (<held> held out ...)`, **reported, never scored**, so no grade moves; proven identical on five files before and after. The bare line filter now carries the measurement above beside it. *Not repaired, on purpose:* the density itself, because widening the numerator re-grades 5,409 files in one unmeasured step, and this file already refuses that shape once by name -- a standing open question is not settled quietly inside a different repair. *Gated:* `tools/fixtures/q/qa_report_card_control.sh` plants **the same ten links four ways** -- running prose, a list, a table, and a bold-key header line -- where it had only ever planted the first, which is the shape the reading can see and would pass on if it counted nothing else; each of the three reads **0 of 10** with the held-out count naming them, none can cost Reach, the report is proven to be arithmetic on the two counts rather than a third measurement, and an elder card given the density reading's own line filters reads **0 of 0** on the list plant, which is the state this ended.
