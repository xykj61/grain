**REDS %490 (`20260906.121059`) -- a map promising *every shipped page* stood green over four of them, because a link into a room lists the room.** *What went wrong:* `docs-geode/wiki/README.md` says in its own second line that it is *the geode's own crosslink map -- every shipped page, what it leads to, and what leads back*. It carried no `**Kind:** crushed index of` declaration at all, so `crushed_index` -- landed nine hours earlier under `%480` to catch exactly this -- reached two indexes and never read it. **And a declaration alone would not have been enough:** the member rule reads ONE level, a member is listed when a link target names it, and a target entering a directory lists the directory. The page links `sangha/README.md`, so `sangha` read listed while the three pattern pages behind that door -- `01-descriptor-exchange`, `02-fact-fold`, `03-five-primitives`, each carrying its own **Witness basis** header -- had never had a row. `%480` gave SHOPPING its row by hand and left the reading where it was; the same page was wrong about three more pages the whole time. *What caught it:* that lap's own closing line, which named the recursive reading as the next step, and then a measurement rather than a memory -- `git ls-files 'docs-geode/*'` minus every `README.md` gives **8** shipped pages, against **5** the page's link targets name. *What it taught:* **a room's door is not the same promise as the pages behind it**, and a guard reading one floor cannot tell the two apart. The elder rule was not loose; it answered a different question correctly, and the page was making a claim that question does not reach. *Repaired (`20260906.121059`):* a second declaration, one word longer -- `crushed index of every page under [link]` -- whose members are every tracked file at any depth minus `README.md` wherever it stands, since a door is a door on every floor. The walk is **bounded at `max_deep_members` = 256**, the tree's own room bound and for the tree's own reason: an index is the page a reader trusts INSTEAD of walking the room, so a listing past 256 stops being one. A deep room over it is refused by name as `index_rooms_oversize` rather than walked in silence. `declared_deep` is reported so the two forms can be told apart from outside. On its first run the guard named all three sangha pages; they have rows now, and the wiki's stale *three announcements* cell was repaired to four in the same pass. Control **23 -> 33 behaviors**, the two declarations proven on ONE tree so the declaration is the only variable, the bound proven from both sides at a distance of one file, and the whole set proven to bite: a scan blind to the deep declaration fails it **5** ways, one with the bound removed fails it **2**. *And one line repaired while passing:* the member pattern escaped `/`, which is an ordinary character in an ERE while `\/` is undefined by POSIX and GNU-only in practice -- harmless and untested while a member was one path component, and on every row once a member is a path. **BOOKED.**
