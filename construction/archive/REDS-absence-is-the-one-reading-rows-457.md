**REDS %457 (`20260906.025440`) -- a whole-tree grep at a stale HEAD is the most convincing way to be wrong about a file's existence.** *What went wrong:* the copal seat was handed `tools/fixtures/f/fleet_login_scan.sh` to run and reported *"does not exist -- no file, no reference to that name anywhere in the tree, tracked or untracked"*, then reasoned onward from that absence to a conclusion about which meters the fleet owns. Every word was true of the bytes it could see. The file had landed **three commits earlier** and that checkout had not fetched; the seat found this itself, rebased, ran the scan GREEN, and rewrote its own log rather than leaving the wrong conclusion standing. *What caught it:* the seat, on its own next move -- which is the half worth keeping. *What it taught:* **absence is the one reading a seat must never take from local bytes alone.** A grep across tracked *and* untracked files is the strongest evidence a lap can gather about a path, and at a stale HEAD it is strong evidence about a tree nobody else is standing in. **On a fleet this is the ordinary case rather than the edge:** eight ships push to one remote, the round-open pulls at lap **start**, and a grep happens mid-lap -- so a checkout is behind within minutes of opening and every lap eventually asks a question whose honest answer requires a fetch. This is `%436`'s family -- *a finding that explains itself well is the easiest kind to publish unverified* -- with the twist that here the evidence was gathered correctly and the **corpus** was wrong. *Repaired (`20260906.025440`):* `tools/fixtures/p/path_absence_scan.sh` answers *absent, or behind?* per path -- it **fetches** the anointed remote first (an upstream reading from a stale remote-tracking ref is the same fault one layer down), prints `commits_behind`, and reports `here=` and `upstream=` for each path. `verdict=absent` requires **both** to say no; a path upstream holds and this tree does not reads `verdict=behind` and says so by name. Proven on all three legs against real state rather than a pen: a path present both ways, a name that never existed, and -- against the live one-commit divergence at the time of writing -- a peer's session log that upstream held and this checkout did not. **OPEN** *(the habit is unenforced: nothing yet makes a lap consult it before concluding a file is gone, and a guard on agent habit costs more than it returns while the habit is one lap old).* *Booked (`20260910.181200`):* re-proven on metal against live divergence rather than a pen -- `commits_behind=1` mid-lap, `tools/fixtures/f/fleet_login_scan.sh` reading `here=yes upstream=yes`, a fabricated name reading `verdict=absent`, and `tools/t/tilak_root_count_witness.rish` -- a witness the anointed spine carried and this checkout did not -- reading `verdict=behind` by name. The remainder is a **habit**, and a lap's own grep sits in no file, so no instrument this tree can own reaches it: the same structural wall `%512` met for a tracked-source scan, `%549` for a shell redirect and `%569` for a signal. The tree's settled answer for that class is the baton, where habits are set -- and the scan wanted one, measured four days after it landed at **zero** mentions across `tools/f/fleet_baton.txt`, `construction/ITINERARY.md`, every rule room, both prompt rooms and the standing roster, which is `%568`'s lesson in a second room. Seated as the baton's `ABSENCE` block and recorded in `.claude/rules/the-baton.md`. **BOOKED**
