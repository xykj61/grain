**BOOKED** -- their instances stand repaired and what remains is a ratchet or a seat -- while the pin

*They share one clause, and it is worth carrying forward on its own. Each is a case of **selecting a
thing by a name that something else also carries**. In `%489`, a seed allowlist was filtered through
a second list naming rooms, so an allowed room shipped nothing and every guard said green. In
`%508`, `pkill -f` selected on a filename that three running agents carried inside their own prompts,
and killed two ships that were working. In `%509`, a ledger row was cited by a number the anointed
remote had yet to allocate, so twenty to thirty-six files spelled a name that was not yet the row's.
Different rooms, one shape: **a name is only a selector while nothing else answers to it**, and the
repair in each case was to select on something the thing actually owns -- a manifest verdict, an
anchored process pattern, a one-clock stamp.*

**REDS %508 (`20260906.173141`) -- a `pkill -f` pattern matched the words INSIDE three running agents' prompts and killed two ships that were working.** *What went wrong:* stopping the watcher by hand with `pkill -f "fleet_watch\.sh"`. Every lap reaches its agent as ONE argv string carrying the whole baton, and the baton had just gained a WATCH stanza naming `tools/f/fleet_watch.sh` -- so `-f`, which matches the full command line, matched three live `claude` processes. `petrichor` and `bakery` took SIGTERM mid-lap and their loops read exit 143. *What caught it:* counting the ships after the re-arm and finding two down that had been up, then reading `pgrep -af` and seeing the baton in the argv. *What it taught:* **this tree already knew this and wrote it down one room over.** `fleet-loop.sh` makes the GATES-ONLY sentinel a FILE rather than a printed word *because the stream echoes the prompt, which contains those letters* -- the same fact, the same trap, and I walked into it with a different tool. **A process whose argv contains a document cannot be selected by any word that document might contain.** *Repaired:* the ships are back up; the anchored form `pgrep -f "fleet-loop\.sh <seat>\$"` that `fleet_watch.sh` already uses is safe by construction, since a prompt mentioning the file mid-sentence never ends there -- which is why the WATCHER never made this mistake and the hand did. *Standing:* select a loop by an anchored pattern, or by the pid its own launcher knows; never by a bare filename. **BOOKED.**
