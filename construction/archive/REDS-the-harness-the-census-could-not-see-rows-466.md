counted 178 Rye files in a set named `never`, documented as *a file no build reaches* -- and 114 of
those 178 were compiled on every parity pass, by a harness that joins a directory in one variable to
a bare stem in another and so writes not one of its 116 paths anywhere in this tree.

The repair is the row's whole lesson. **A label that is wrong because the instrument cannot see is
cured by widening the sight, never by softening the word.** The resolver already existed one file
over, so the census asks it rather than learning to read a harness a second time -- one resolver, two
readers, and the credit conditional on the harness actually compiling, so asking widens what is seen
without widening what is believed.

have reached these files anyway**: its reading intersects the never set with the paths a *reading*
runner spells literally, and a harness spells none -- so the bound is written down now rather than
assumed. And **a tree holding no harness and a copy that cannot answer look identical in the paths
alone**, which is why the answer carries a marker ahead even of its own refusal.
