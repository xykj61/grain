*It files alone because its lesson is one sentence and that sentence is now a reflex the fleet
reads every lap: **a guard that cannot run its instrument refuses by naming the instrument, rather
than reporting the thing it could not reach as broken.** `agent_jail_witness` launched
`agent-jail.sh` for real from inside a sandbox whose kernel refuses the mount namespace bwrap
needs, and reported the jail broken when nothing about the jail was wrong. The mechanism that fixes
it was already built and seated -- the roster's `capability` field, where only a positively-read
`absent` skips and `unknown` still runs the guard -- and a peer wired it. The row's one nuance
survives here for whoever reads it next: **bwrap MISSING and bwrap REFUSED both exit non-zero, and
only the second is a capability absence**, so a host without bubblewrap must still red honestly.*
