**REDS %582 (`20260907.154440`) -- a wipe was read as a flag rather than as an act, so a scan that removed a peer's in-flight file every run was classed survivable, and it took a rostered guard down.** *What went wrong:* `tools/fixtures/s/shipped_binary_claim_scan.sh` truncated `/tmp/sbc_hits.txt` with `: >`, appended its grep hits, counted them with `wc -l`, and removed the file -- one constant name under the single `/tmp` eight ships share. `tools/fixtures/s/shared_pen_scan.sh` counted both of its sites and classed them **hold**, a class whose whole definition is the claim that a writer *may interleave with a peer and survive*. The claim was false of exactly those files, because the wipe predicate demanded an `r` or `R` flag (`rm[ \t]+-[a-zA-Z]*[rR]`), so `rm -f <a plain file>` was invisible to it: the reading asked how a removal was spelled rather than whether one happened. *What caught it:* this pier's cold pass of `20260907.150519`, where `shipped_binary_claim` answered red and `standing_equipment` answered `roster_broken` behind it -- and the witness ran **GREEN alone** one minute later, which is `%549`'s published signature. *Proven on metal, both directions, before anything shipped:* eight concurrent copies of the elder scan against one pen holding exactly one claiming page, three rounds, **24 of 24 runs wrong** -- some printing `claims_found=4` because four processes' hits had accumulated in one file and every process counted all four as its own, others printing no count at all because a peer had removed the file mid-read. Eight concurrent copies of the repaired scan on the same pen: **0 of 24 wrong**. *What it taught:* **a guard's own exemption is a claim, and this one was never measured.** The hold class was reasoned rather than read, and the sentence that justified it was the sentence that hid its own counterexample -- `%544`'s lesson in this same file, one predicate over: *a limitation written down honestly still hides its own size, because the sentence naming a blind spot is written from inside it.* The sharper half is that the two spellings are one act: removing an in-flight **file** takes a peer down exactly as removing its directory does, and only the flag differs. *Repaired (`20260907.154440`):* both scans carrying the shape took private `mktemp -d` pens with traps -- `shipped_binary_claim_scan.sh` and its line-for-line sibling `tools/fixtures/d/documented_room_scan.sh` -- each witness GREEN on metal after.
