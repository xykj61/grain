it ever received: molt first, repoint the living, wait for the circle, checkpoint, cut, then
read the wound with the census. The name is the Sanskrit friend, the Vedic keeper of
covenants -- a cut that keeps faith.

## The code horizon, named honestly

Still to be written, each its own round when its day comes: a `mitra.rye` that takes one
candidate path and prints its **shed readiness** -- inbound living citers counted, mutant
located, banner checked, class row found -- derived fresh from the tree rather than stored
anywhere; and a witness proving the readiness reading refuses a candidate whose mutant is
missing. Until then the discipline runs on the instruments above, and this door is the
module: a room may be seated by its documentation first, with its code arriving under the
same callings that govern every other seat.

The circle stays Keaton's word in every case; nothing in this room will ever cut on its own.
