## What we are naming

Grain's multi-season workflow -- nested clocks, pause/handback, waymarks, living pins vs dated fossils, Cursor/Claude dual editors -- wants a plain name outsiders can hear and a precise house name when depth matters.

**Plain name:** Season-Driven Development (**SDD**).  
**House-precise:** Nest-Season Development (when emphasizing nested pause stacks).

## Kin and contrast (understanding only)

| Pattern | Kinship | Honest difference |
| --- | --- | --- |
| Agile / Scrum sprints | Time-boxed increments - review cadence | SDD nests **pause parents** rather than collapsing all work into one backlog sprint |
| Shape Up (cycles + cool-down) | Appetite - fixed time - cool-down | SDD keeps **multiple paused clocks** and an explicit **handback lean** |
| OKRs / roadmaps | Direction above tasks | ROADMAP/TASKS remain; seasons **consume** them at a finishing edge |
| Gitflow / trunk-based | Branch discipline | SDD's "branch" is a **season nest**, not a git branch (though commits still ship) |
| Zettelkasten / evergreen notes | Living vs dated notes | Maps to **living pins** vs **fossils** - foundations vs archive/yonder |
| Clean-room / gratitude shelves | Study without copy | `external-research/` + `gratitude/` already encode this |

## Why SDD fits agent+human benches

1. **Finishing edge** -- one nest OPEN; others PAUSED/CLOSED. Ambiguity drops.  
2. **Waymark** -- tiny paste-back beats reloading a novel each session.  
3. **Handback** -- `return_<parent>_<bookmark>` is a typed exit, not a mood.  
4. **Dual editors** -- mechanical kg vs seam/ruling check-in stays explicit.  
5. **Accrete, don't rewrite** -- one-clock stamps; living rename-forward; no force-push for vocabulary tidy.

## Risks to watch

- Nest tower too tall -> prefer handback before opening nest N+1 without a named breach.  
- Long recursion paste every round -> noise; reserve for season open.  
- Treating SDD as a slogan without witnesses -> every OPEN nest still needs GREEN benches.
