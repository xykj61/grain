#
# One row per ceiling: <scan basename>|<ceiling key>|<reading key>. This is the one thing
# tools/fixtures/r/ratchet_slack_scan.sh cannot derive, because each scan names its own reading:
# `absent` beside `absent_ceiling`, `plain_shebang_ratchet` beside `plain_shebang_ceiling`, and a
# bare `chars` beside a bare `ceiling` in the four ASCII meters. A ceiling with no row here prints
# `reading=unread` and is counted; a row naming a ceiling this tree no longer declares prints
# `stale_pair` and refuses. A reading key may carry a line anchor, `ANCHOR@key`, where a scan
# prints one key name on two lines -- `rye_comment_ascii` says `chars=` for own-line comments and
# again for trailing ones, under two ceilings. Blank lines and `#` lines are read past.
