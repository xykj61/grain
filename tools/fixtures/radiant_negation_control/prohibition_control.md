# Prohibition control -- prose written entirely as bans.

This file is never a living rule. It exists so the guard's refusal is shown on metal.

Do not do this. Never do that. No exceptions are permitted, and nothing else is allowed
either. You cannot proceed, you must not proceed, and nobody may proceed. This is not a
suggestion. It is not optional. There is no alternative path, no second reading, and no
appeal. Never assume otherwise; do not ask again.
