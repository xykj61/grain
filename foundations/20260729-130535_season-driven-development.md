## Name

**Season-Driven Development (SDD)** — work advances by **seasons** (fixed round budgets, usually N = 2ᵏ) with one **finishing edge**.

When many seasons nest: call the depth stack **Nest-Season Development**. Living deepest label moves with the OPEN nest (**nona** today; was wrongly frozen as “innermost” on MUR).

## Season open checklist (template)

1. **Pause** the parent nest; record bookmark (`p40/p41`, etc.).  
2. **Charter** — scope word · round letter · N · handback lean · hard lines.  
3. **n0 / p0 / … bow** — seat recommendations; name first door.  
4. **`prin_scope.rish`** — print all nests; OPEN only the new one.  
5. **LEXICON** — season name + scope word.  
6. **Long recursion paste** once (expanding-prompts).  
7. **Waymark** every later round (short form).  
8. **Witness** for the bow when metal exists.  
9. **Send** (signed commit · push) at round close unless hold.

## Handback

Always name `return_<parent>_<bookmark>` at season open. Closing warn rounds ask extend vs return. Parent resumes at its bookmark; child stays PAUSED.

## Hard lines

- One OPEN finishing edge (plus named parallel PREP/PARK that do not steal rounds)  
- No force-push to tidy vocabulary  
- No shred/deploy/keys from season paste alone  
- Roadmap tasks enter seasons by name; seasons do not silently invent infinite scope
