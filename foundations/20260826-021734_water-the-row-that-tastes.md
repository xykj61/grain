## The sense: taste

Water tastes. The tanmatra pairing (Keaton's word, 20260826) gives each element row one
sense, and this row's is the tongue: the lap tastes whether the flow is sweet or off. Taste
is the intake sense -- what you taste is already inside you -- so a water lap reads by
swallowing: take the document in, hold it a moment, and notice the aftertaste. A seam that
reads bitter, a test suite that has gone brackish with integration weight, a design that
was sweet last chapter and is cloying now -- the tongue reports these before any meter
does. Where fire's vision measures at a distance, taste only works up close, and that
closeness is the row's discipline: read the actual file, run the actual witness, sip the
actual code.

    declaration + world  ->  infusion  ->  world'
    infusion(world')     ->  world'          idempotent

The first line says a declaration and a world produce a new world. The second carries the
weight: infusing that new world again yields the same world, so running a change twice does
what running it once did. A tool that fails it corrupts on its second run -- and the second
run is what an unattended loop performs at three in the morning.
