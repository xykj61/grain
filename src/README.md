- [`til/`](til/README.md) — **tilaks**, the type-marks networked values wear at every seam.
- [`sur/`](sur/README.md) — **structures**, the data-shape museum: each shape in isolation, in beauty.
- [`app/`](app/README.md) — **Pool agents**, the applications.
- [`gen/`](gen/README.md) — **generators**, the runnable demonstrations (318 desks arrive here from `glow/gen/` when the O2–O3 breach speaks).
- [`lib/`](lib/README.md) — **libraries**, the shared gates.

The migration is designed, declared-not-begun, under [`../context/BREACH.md`](../context/BREACH.md); the design lives in counsel. Until the breach speaks, `glow/gen/` remains the desks' one true address.

*May every room fill in its own season, and no address move before its witness stands.*
