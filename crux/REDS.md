## Why this file, and what belongs in it

Own-reds-immediately has been a house law for a long time, and it worked: reds were named the moment they were found, out loud, without excuse. What the law never said is **where**. So the ones that happened to land inside a witness header or a spec erratum survived, and the ones that happened in a sentence did not.

Three fields per row, because a red with fewer teaches nothing:

- **What went wrong** -- stated plainly, no softening.
- **What caught it** -- a compiler, a stopwatch, a guard, a second look. Never "I noticed."
- **What it taught** -- the transferable rule, which is the only part that outlives the incident.

A red enters this ledger when it is found. Rows are never edited or removed; a later correction accretes as a new row pointing back.

**REDS %92 (`20260820.003328`) -- the whole Caravan arc was green only on a warm tree.** *What went wrong:* **36 of the 52** Caravan witnesses run `caravan/bin/read` to load a declaration, and not one of them built it -- `caravan/read.rye` is compiled by `caravan_read_witness.rish` alone, which the roster sings **after** most of its borrowers. So on a clean checkout the arc's first rung fails, and every GREEN this choir ever reported was standing on a binary some earlier run happened to leave behind. *What caught it:* clearing `caravan/bin` while chasing REDS %88, then re-running the suite -- which named `tools/caravan_arrange_witness.rish` RED, and named it **only because #89's fix had landed an hour earlier**; before that the same failure read `a per-rung witness went RED -- ${w}`. Two reds closed in this round were what made the third visible at all. *What it taught:* **a witness owns what it runs.** Borrowing a sibling's artifact turns a suite into an ordering puzzle whose answer changes with the state of a directory nobody is watching, and the failure it eventually produces points at an innocent rung. Closed two ways: each of the 36 now builds `caravan/read.rye` itself, so any rung runs alone on a cold tree; and the choir **clears `caravan/bin` before it sings**, which makes cold-start self-sufficiency a fact this witness checks on every run rather than a property nobody was measuring. **REDS %88 (`20260820.002850`) -- two witnesses building at once corrupted each other, and the tree read it as three failing rungs.** *What went wrong:* every `tools/glow_run_worker.sh` invocation rebuilt `glow/bin/glow_run` and wrote `glow/.cache`, and it emitted straight to the final path. So a sweep running beside a hand-run gate wrote the same bytes from two processes: the lane that lost executed a half-written binary and reported RED **about its own logic** while nothing was wrong with it. A build killed midway left a truncated `glow_run` standing, which the next entirely clean run then trusted. *What caught it:* the Caravan `child` -> `dependent` molt round -- `caravan_glow_tend_limb1/2/3` went RED together and re-ran GREEN twice with nothing changed between them, and `aurora_wire_a1` and `mantra_gen_floor_a1` fell in the same breath. Three witnesses failing and passing on identical bytes is the signature of contention, never of a defect. *What it taught:* **a shared build artifact is shared mutable state, and a witness surface that cannot be run twice at once will eventually lie about the code it watches.** Two guards, in TAME's order of safety before speed: builds serialize behind one **bounded** lock (a wait that reports rather than hangs), and every binary is emitted to a private path and moved into place with `rename`, which is atomic -- so an interrupted build leaves the previous good binary rather than a plausible ruin. The Caravan choir's roster lists became per-run for the same reason. Closed on metal by `tools/glow_build_concurrency_witness.rish`: a twin **generated from the real worker** with exactly those two guards stripped fails 5 of 6 parallel lanes with a compiler panic, while the guarded worker fails 0 of 6, answers `EXIT:0` on every lane, and leaves nothing half-built. Generated rather than kept, so the control can never drift from the worker it controls. Released.

**REDS %89 (`20260820.002850`) -- every RED message in this tree was hiding its own cause.** *What went wrong:* Rishi's `assert <cond> else "<message>"` printed the message's **literal text**. `say "${x}"` had always interpolated; the assert message alone never did -- `do_assert` stripped the quotes and printed the raw bytes without ever calling `interpolate`. So `else "build failed -- ${build.err}"` reported `${build.err}` and named nothing. Measured across the tree: **1,632 such messages in 731 witness files.** *What caught it:* diagnosing #88. The Caravan choir's own failure line read `a per-rung witness went RED -- ${w}`, which named none of its 52 rungs, forcing a hand-rolled loop over every witness to find the one that broke -- and the answer, once found, was that nothing had broken. The bug's cost was almost entirely the diagnostic's silence. *What it taught:* **the message a failure carries is part of the failure.** A diagnostic that cannot render its own facts costs more than the fault it reports, and the gap hid in plain sight for as long as it did precisely because it only ever appeared on a path people were already unhappy to be on. Fixed in `rishi/src/main.rye`: `do_assert` now tracks whether the reason was quoted and renders it through `assert_message`, so a **quoted** message interpolates like every other string in the language, an **unquoted** reason is shown exactly as written, and a message that **cannot** render falls back to its own raw text rather than replacing the failure with a second one -- the assertion is the news. All 23 `rishi/tests` GREEN, the six `rishi_*` witnesses unchanged in behaviour. Released.

## What the pattern says

Read down the *what caught it* column and almost nothing was caught by thinking harder. A compiler, a stopwatch, a file-type check, a guard's first run, seven witnesses at once, a pack catching its own author. **The machine caught nineteen of twenty.**

That is not a complaint about judgment; it is the argument for the whole apparatus. Witnesses exist because the author is the last person able to see their own gap, and this column is twenty lines of evidence for that claim rather than one more assertion of it.

Read down the *what it taught* column and four rules recur: **measure before claiming**, **scope before shipping**, **fixture rather than remember**, and **narrow the objection**. Those four have paid for themselves repeatedly in a single sitting.
