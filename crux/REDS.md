## Why this file, and what belongs in it

Own-reds-immediately has been a house law for a long time, and it worked: reds were named the moment they were found, out loud, without excuse. What the law never said is **where**. So the ones that happened to land inside a witness header or a spec erratum survived, and the ones that happened in a sentence did not.

Three fields per row, because a red with fewer teaches nothing:

- **What went wrong** -- stated plainly, no softening.
- **What caught it** -- a compiler, a stopwatch, a guard, a second look. Never "I noticed."
- **What it taught** -- the transferable rule, which is the only part that outlives the incident.

A red enters this ledger when it is found. Rows are never edited or removed; a later correction accretes as a new row pointing back.

## What the pattern says

Read down the *what caught it* column and almost nothing was caught by thinking harder. A compiler, a stopwatch, a file-type check, a guard's first run, seven witnesses at once, a pack catching its own author. **The machine caught nineteen of twenty.**

That is not a complaint about judgment; it is the argument for the whole apparatus. Witnesses exist because the author is the last person able to see their own gap, and this column is twenty lines of evidence for that claim rather than one more assertion of it.

Read down the *what it taught* column and four rules recur: **measure before claiming**, **scope before shipping**, **fixture rather than remember**, and **narrow the objection**. Those four have paid for themselves repeatedly in a single sitting.

**REDS %116 (`20260821.183454`) -- the fix that was asked for would have rewritten every content address in the tree.** *What went wrong:* Amphora lap 2 had been RED for want of `openssl`, and the repair proposed -- by me, in the round before -- was to teach its export the `sha256sum` already on the pier. That is the wrong fix and it would have been a quiet one. Every call in that path is `openssl dgst -**sha3**-256`, and **SHA3-256 is Keccak while sha256sum is SHA-2** -- different algorithms, not two spellings of one. The substitution would have compiled, run green, and silently changed every content address in every manifest this tree has ever written, and each new digest would have looked exactly as much like a digest as the old one. *What caught it:* reading what openssl was actually being asked to do before substituting for it, rather than pattern-matching on the word `sha256`. The tree's own hash-tier spec names **SHA3-256** for the Working tier in plain text, one grep away. *What it taught:* **a substitution is only safe once you know what the thing being substituted for actually computes.** A hash tool is the sharpest case -- wrong output is indistinguishable from right output by inspection, there is no crash to notice, and the damage lands in exactly the artifacts meant to be immutable. *The repair, on metal:* `crypto/sha3_file.rye` computes the digest over this tree's **own authored Keccak-f[1600]** (`crypto/sha3.rye`, clean-room from FIPS 202) -- the same algorithm, the same digests, no external dependency, and one more place the tree stands on what it built. Five fixtures moved from openssl to it. Amphora laps 1, 2, and 3 are **GREEN**, as are all seven Amphora and Cellar witnesses. *And the oracle question is answered rather than dropped:* the hash-tier spec called openssl the **independent host oracle**, and a digest checked only against the code that produced it proves nothing -- so `tools/sha3_file_witness.rish` checks ours against the **published FIPS 202 known-answer vectors**, which anyone can look up and nobody here can quietly change, and against openssl additionally wherever it is installed, reporting honestly when it is not. One more thing the repair found: the tool first printed a perfect digest through `std.debug.print`, which is stderr, so every `$(...)` around it read the empty string -- and an empty digest is precisely what wrote the short manifest line whose reader then died on an unbound field. The digest goes to stdout now, and the witness proves it is capturable.
