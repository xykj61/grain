This version splits the filled autonomous-loop prompt by seat rather than growing it again.
Three sessions run the tree in parallel -- Claude Desktop, the Vultr SEA pier, and the ChatGPT
Arbor session -- and each now reads a prompt bearing its own name, lane, and remote spelling,
with the shared discipline carried by `construction/ITINERARY.md`'s INNER LOOP Standing block
rather than restated in every prompt. A directive seated on the card reaches all three stars on
their next lap with no launcher edit, which is the token economy the split is for.

The living, runnable prompts are printed by their launchers -- the launcher is the version:

- **Mind, cardinal** (Arbor, macOS -- Brushstroke - Surf): `rishi/bin/rishi run tools/l/launch-mind-cardinal-chapter.rish`, and the spoken loop itself at [`../../arbor/launch-chatgpt-chapter.brix`](../../arbor/launch-chatgpt-chapter.brix), whose eight tiles name the seat.
- **Sound, fixed** (Claude Desktop -- Caravan - Tally - toroidal - the Scribe seams): `rishi/bin/rishi run tools/l/launch-sound-fixed-chapter.rish`.
- **Dream, dual** (the pier -- Glow runes lowering to Rye; the seed cadence rides here): `rishi/bin/rishi run tools/l/launch-dream-dual-chapter.rish`.

The elder single-prompt recipe stands unchanged at
[`../../tools/l/launch-claude-chapter.rish`](../../tools/l/launch-claude-chapter.rish) for a
bench that runs alone.
