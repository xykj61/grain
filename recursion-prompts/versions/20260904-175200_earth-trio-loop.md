## Three ships, one engine, one loop

Every Earth seat runs **Claude Code** through **one** outer loop, from the tree that holds it:

```
cd ~/grain-incense    && sh tools/l/fleet-loop.sh incense
cd ~/grain-pheromone  && sh tools/l/fleet-loop.sh pheromone
cd ~/grain-petrichor  && sh tools/l/fleet-loop.sh petrichor
```

| Ship | Tree | Lane |
|---|---|---|
| **Incense** | `grain-incense` | law, active-designing, iterative review -- and the captain's hat |
| **Pheromone** | `grain-pheromone` | the molecular star; the language details a rune wants |
| **Petrichor** | `grain-petrichor` | `docs-geode` (tend, never rename) and prose-product |

The prompt each seat reads is a **file**, `tools/l/<seat>_seat_prompt.txt`, never an inline shell
string -- an apostrophe inside a single-quoted one-liner strands the shell at its continuation
prompt, which is how Silence's loop broke on `20260829`.

**What is new in this fill, and it is a subtraction.** The aether version listed three launchers,
one per star, and said *the launcher is the version*. Three Earth ships share one launcher and one
loop, so the version is the roster and the seat prompt. A directive seated on
`construction/ITINERARY.md`'s INNER LOOP Standing block still reaches every ship on its next lap
with no launcher edit -- that token economy is unchanged and is the reason the split existed at
all.

## Machines are doors

A seat is a chair, not a computer. **Incense** and **Pheromone** loop from their own trees on the
Mac; **Petrichor** loops from the Dallas pier. The captain sits at either door -- the Mac's
`~/grain` field GUI, or the pier over SSH from a Daylight DC-1 tablet -- and the rule that makes
this safe is one sentence: **one writer per checkout** (REDS `%291`). Before opening a door, prove
the other is closed, and open with the twice-pull so anything the far door landed arrives first.

**The pier door opens in `~/grain-incense`, and there is no `~/grain` on Dallas.** The captain
prompt of `20260904.171306` named the pier's clone `~/grain` and the card had already recorded
otherwise; `sh tools/f/fleet_rearm.sh` reads `/home/keeper/grain` as **absent** on this host, and
all three Earth trees are present beside it. The Mac keeps `~/grain` as the field GUI sitting. Both
doors are real; only one of them has a tree by that name.

## What every lap keeps

Carried whole from the aether fill and the six-body charter, because all three earned their
evidence:

- **Reds first.** A red books the remainder of the allocation. A fix closes on a witness on metal.
- **Claim-as-override.** An empty lane takes the oldest unclaimed booked lap from any lane rather
  than stopping. The claim is named in the session log and its day-shelf row; the owner reviews at
  their next sitting; custody gates still stop the lap; a claim never touches a peer's in-flight
  work.
- **Custody gates stop every ship.** Funds and keys, provisioning and paying, the maintainer's own
  identity, the public seed. If only gates remain: `touch .loop-gates-only`, print `GATES-ONLY`,
  stop.
- **Grade what you touch**, B or better stands. **Read scope** -- open shelves walked, closed
  stacks fetched by named path. **Stamp and name**, never an ascending mark. **ASCII-first.**
- **A session log ends every lap**, born on its day's shelf, its row prepended to that day's index,
  committed with the work.

## The Linux wrap, and the one thing that broke it

On the pier each lap runs inside `tools/ag/agent-jail.sh`. Two facts a fresh pier needs, both
learned by measurement on `20260904`:

- `ai-jail` v1.20.2 **defaults network off**; the launcher passes `--network`, and without it the
  API never resolves.
- `--private-home` makes `$HOME` a tmpfs, so **`~/.claude.json` -- where Claude Code keeps
  `hasCompletedOnboarding` and the chosen theme -- is absent unless the launcher mounts it.** The
  mount was conditional on a file only the jailed Claude could write, so onboarding ran on every
  jailed launch and its theme picker previewed a light scheme that reads as invisible text on a
  dark terminal. Seeded and mounted unconditionally from REDS `%408`; the pier's NixOS
  configuration was measured and is not at fault.

`FLEET_BARE=1` is the named bare fallback, and a lap that takes it says so in its log.
