# Section names -- the shared headings for the recurring sections

**Status:** Living
**Room:** checkable

The one list of section headings that recur across the living pages in `context/`. A page that
has one of these sections uses the heading here. Referenced from the clean-slate tree's
`context/lib/section-names.md` (`grain-ww/20261015-grain`), adapted for petrichor.

| Heading | Used for | Where it recurs |
|---|---|---|
| `## Role in the tree` | what a page or voice does in this tree | voice pages, style pages |
| `## Register` | the prose register a page writes in, and what it keeps | voice pages, style pages |
| `## Limits` | what a page or voice keeps out | voice pages, rule pages |
| `## Outcome` | what a plan or a round produced, read from git | plans, composition entries |
| `## Open tasks` | the items still waiting, with what each waits on | project pages, plans |

## What is not in the list

A descriptive title that names its own page, such as "The moves" or "Where it is reached for,"
stays as it is. This page names the headings that recur across many pages, so a reader finds
the same heading in the same place. A heading that belongs to one page alone is that page's own.

## How a page uses it

Use the heading here when the content matches the row. A page with no open tasks omits that
section rather than carrying an empty one.
