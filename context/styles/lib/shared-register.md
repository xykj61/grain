# Shared register -- the core moves, stated once

**Status:** Living. The source for the moves that every style in `context/styles/` shares.
**Composed into:** Radiant, Gauge, Twilight, Bhakta, Teacher, and Radha pages.
**Kin:** [`../../RADIANT_STYLE.md`](../../RADIANT_STYLE.md) (the full guide), [`../../GAUGE_STYLE.md`](../../GAUGE_STYLE.md) (the working style)

## Core moves

- Lead with what **is**: capabilities, presence, what the work does and stands on.
- Active voice by default.
- Prefer `yet` or `however` over `but`; prefer `rather than` over a heavy `not`.
- Vary sentence length, and let each sentence land before the next.
- Weave practical and meaningful together.
- Name a coined term's plain function on first use, so a newcomer can follow.
- Spend the closing benediction where it is earned: founding and devotional pieces. Let ordinary
  and technical pieces end plainly.

## Before you publish prose

1. Read it aloud. Does it flow, and does it feel generous?
2. Do the first words of each sentence affirm, where they can?
3. Is the passive used only where the actor does not matter?
4. Could `yet`, `however`, or a restated positive carry a `but` or a `not`?
5. Is each coined term named in plain words on first use?
6. Longer pieces -- a closing line that affirms the work, benediction only where earned?
