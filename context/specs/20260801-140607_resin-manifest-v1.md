## Why this file

Journey Four owes a written home for the format the benches already practice:
a zip that crosses from counsel to pier (or pier to counsel), carrying patches,
tree snapshots, and a sha3-addressed manifest. Q55 seats that practice as
spec — not a rewrite of the living zips, a roof they already fit under.

## Container

- One zip archive, named `YYYYMMDD-HHMMSS_<span>_resin.zip` (one-clock).
- Top directory `resin_<slug>/` holding:
  - `BUNDLE.manifest` — this format
  - zero or more `NNNN-….patch` files (git-am shaped, ordered)
  - optional `tree/` snapshots of files that must land whole
  - optional `CURSOR_FUSING_PROMPT.md` — human fuse steps for the far bench

## `BUNDLE.manifest` — resin-manifest-v1

Bron-like plain text, one field per line, no quotes:

```
format resin-manifest-v1
stamp YYYYMMDD.HHMMSS
seat <short seat meaning>
basis <full or 10+ char git hash the resin expects>

bead <sha3-256 hex> <byte_len> <relative path>
bead …
```

### Field law

| Field | Law |
| --- | --- |
| `format` | Exactly `resin-manifest-v1` until a superseding dated spec lands |
| `stamp` | One-clock Eastern (or named zone) of the mint |
| `seat` | Human span — which quests / why |
| `basis` | Git tip the patches apply against; different tip ⇒ re-cut, never force |
| `bead` | Content-address: SHA3-256 of the file bytes · decimal length · path inside the resin dir |

### Bead law

- Every file that must verify is a bead row (patches, tree files, prompt).
- Path is relative to the resin directory root (not the zip root alone).
- Far side proves `sha3(path) == bead` and `len(path) == byte_len` before landing.
- Missing bead · wrong digest · wrong length ⇒ refuse the whole resin loudly.

## Supersede law

- Living docs the resin updates follow **accrete-never-break**: a better draft
  is a new dated artifact or an explicit supersede line — never a silent
  claim rewrite on dated testimony (REDS 47).
- Elder patches stay in history; a re-cut resin names a new basis and new beads.
- Personal beads (keys, PERSONALIZE, key-card) land only on Keaton's word;
  without a word they refuse loudly (relay_resin shape).

## Fuse law (far bench)

1. Measure living tip; if ≠ `basis`, re-cut or three-way merge — never force-push.
2. Verify every bead.
3. Apply patches in order (`git am` when the tip matches) or land `tree/` files
   by merge that keeps both benches' truths.
4. Rebuild · run named witnesses · dual-push origin + xykj61.
5. Session-log README rows in the pier's newest-first habit.
