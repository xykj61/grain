## Movement II — The Power-of-Two Scope

The 256-season charter (`../counsel/20260730-022147_the-256-season-charter.md`) already names the nesting exactly:

> "Four equinoxes. Sixteen journeys in each equinox. Four quests in each journey. One round in each quest. Four times sixteen times four times one is 256 rounds, and the season carries its number honestly."

So the clean ladder, smallest to largest, each level four of the one beneath it:

| Level | Size | The unit |
|---|---|---|
| **Round** | 1 | one lap — one keystone, one witness |
| **Quest** | 4 rounds | a small arc that finishes one thing |
| **Journey** | 16 rounds | a themed stretch (four quests) |
| **Equinox** | 64 rounds | a great movement (four journeys) |
| **Season** | 256 rounds | the whole (four equinoxes) |

One season, four equinoxes, and every equinox is a compass point — which is why this baton proposes the season's name be **The Compass Season**: the whole system scoped by the four directions the project already tells itself to follow.
