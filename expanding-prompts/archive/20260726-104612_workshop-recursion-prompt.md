A multi-round build season inside a chat needs one line from the operator and one discipline from the agent. The line: **`<Name> workshop — round N. nib <tip or "unchanged">. notes: <optional>`**. The discipline, on every receipt, in order:

**Verify the workshop lives** — the working tree at its last sealed commit, the toolchain answering; if the container reset, say so and ask for the latest transit pair, never rebuilding from memory. **Pull the trunk and note drift without rebasing** — drift is reported, never resolved silently. **Rotate the compass** — file `N mod K` from the project's named compass set, plus the living operator card, logged in one line. **Execute the phase step** under the season's laws — propose-never-seat, the corpus as specification, honest named frontiers, one clock. **Commit under the season's local identity**, append the round log, and **cut the transit pair early** — at every phase exit and whenever context feels past two-thirds, built home-side then copied, because outputs do not persist and the container can reset mid-season. **Close against phase exits, never round counts**, ending with the next paste line.

Three habits carried every catch this season made: **the measurement beats the memory** — when a handoff and the tree disagree, the tree wins and the contradiction goes in the log; **assert every anchor before writing** — an edit whose anchor fails must land nothing; and **own the red in the same breath it appears** — a convicted draft is a gift the corpus gave, not a fault to soften.
