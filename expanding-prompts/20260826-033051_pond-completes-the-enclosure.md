## The intent, in one line

Pond grows until it holds every duty the tree borrows from ai-jail -- the enclosure an agent
builds inside -- and the borrowed jail is then retired by a planned deep debride, on Keaton's
word alone.

## What ai-jail provides today, named honestly

The GPL-3.0 jail (a gitlink, studied never copied) gives this tree four things: an isolated
build enclosure the editors launch into; an ephemeral host -- $HOME, /tmp, and parent paths
reset on exit while the project directory persists; a working GPU passthrough on GNOME Wayland
(`USE_GPU=true`); and per-host jail keys kept separate on purpose. Pond replaces the jail when
it holds all four on its own floor, proven by witnesses rather than by resemblance.

## The floor already standing

Pond is the application module: 181 app sources, `customs.rye` deciding place - hold - refuse
at receipt, enclosure policy running what Brix composes. Caravan holds the isolation-shaped
pieces the enclosure needs -- `address_space.rye`, `capabilities.rye`, `allowances.rye`,
`regions.rye` -- and the rearchitecture essay's moves (wrap named, sets word-wide, drains
replayable) harden exactly the seams an enclosure leans on. Tally bounds the memory. Kyri 6
receipts what the enclosure admits and refuses. The quest composes what stands; it invents
as little as possible.

## The quest -- five orbits, seventy-five rounds

**Orbit one -- policy as a value.** The enclosure policy (mounts, namespaces, network, the
ephemeral set) written in Brix, evaluated to Kyri records, checked by customs at receipt.
Done when a planted policy round-trips and a forbidden mount refuses by name.

**Orbit two -- the isolation floor.** The policy driven through Caravan's capability and
address-space pieces on Linux primitives (the jail's own substrate), each grant derived from
the declaration the witness reads -- one source of truth, the roster discipline. Done when a
supervised child sees only what its policy names, proven by a witness that tries to escape
and is refused.

**Orbit three -- the memory that forgets.** The ephemeral host: an enclosure whose $HOME and
/tmp dissolve on exit while the pier persists -- the Mikrophone's forgetful-capture pattern
at enclosure scale. Done when a planted secret written outside the pier is provably absent
after the enclosure closes.

**Orbit four -- the doors.** `launch-claude-chapter.rish` and the Zed launch path enter
through Pond instead of the jail, jail keys become Pond enclosure keys per host, and the GPU
passthrough seam is carried or honestly gated per platform. Done when a full working chapter
lap runs start to finish inside a Pond enclosure on this tree's own piers.

**Orbit five -- the switchover and the shed prep.** Both piers run Pond enclosures for every
unattended lap; the jail's gitlink and launch references molt to fossils with the enclosure
spec repointed; the gratitude note stays, re-voiced as thanks to a retired teacher. Done when
no living path invokes ai-jail and a five-round soak holds GREEN.

## The deep debride, planned and gated

When orbit five closes, the **ai-jail deep debride** stands ready: the gitlink removed from
tree and history, checkpoint recorded first, both remotes force-pushed, every clone
re-cloning once -- the same discipline the DJINN and chapter debrides proved this chapter.
The gratitude is kept; the dependency goes. **This plan grants nothing of that execution:**
the debride runs only on Keaton's explicit later word, and until then the jail stays thanked
and pinned exactly where it stands.

## Custody gates

Sandbox security seams are check-in territory: any round that weakens an isolation boundary,
touches key custody, or opens the enclosure's network stops and surfaces. The switchover
round and the debride word are Keaton's alone. Every falsifier is the same shape: an escape
the witness catches sends its orbit back to design.
