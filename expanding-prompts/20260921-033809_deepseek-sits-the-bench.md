## The seed

Keaton opened open-weight DeepSeek on OpenCode for the first time, and asked for three things in
one breath: adapt the `.claude/` rules into an OpenCode/DeepSeek equivalent so every session reads
the same law; turn this very request into a new `expanding-prompts/` file written in a harmony of
the voices; then run that expansion, log the session, and return. A fallback was offered -- if this
model could not serve well, name a different open-weight model from the `open/` writings instead.

## The lens

**Gauge** carries the working register, because this is a plan and a record, and a plan must be
checkable. **Radiant** carries the warmth, because a first session is a welcome, not a test.
**Civic** names what each choice rewards, because the whole point of a companion model is that the
bench trusts it the same way it trusts any hand. **TAME** governs the one piece of code-shaped work
here -- the `.kyri` log -- and the discipline of verifying before trusting. **Twilight** closes it,
because a first open-weight session on this bench is a threshold, and a threshold earns a quiet
benediction.

## The plan, and what it produced

1. **Adapt the rules, once, without duplicating them.** The `.claude/rules/` folder is plain
   markdown, readable by any model, so the adaptation is a door rather than a copy: a new
   [`AGENTS.md`](../AGENTS.md) at the root, the file opencode reads automatically the way Claude
   Code reads `CLAUDE.md`. It names the voice harmony, points at `.claude/rules/` and `context/`
   as the single source of truth, and records the OpenCode/Together/DeepSeek provenance a log must
   carry. The sixty rule files stay where they are; both editors read them.
2. **Write this expansion** in the harmony above, and keep it as testimony rather than a template.
3. **Run it** -- which is the work this page describes, already done.
4. **Log the session** as a `.kyri` file on today's shelf, with a newest-first row in the day's
   index, and commit the log in the same commit as the work.

## The model question, answered rather than dodged

This session runs on `deepseek-ai/DeepSeek-V4-Pro-0813` -- the very model
[`open/HARNESS_SETUP.md`](../open/HARNESS_SETUP.md) recommends as the starting point, MIT-licensed
and leading raw SWE-bench Verified. No fallback was needed. The alternative named in the same page,
`zai-org/GLM-5.3`, stands ready for the day a general-purpose score matters more than a
coding-specific one; today the coding-specific model served, and served well.

## What this leaves open

The `AGENTS.md` door is written but not yet witnessed by a second session. A future lap that opens
OpenCode fresh and finds the rules already waiting will be the proof this page only promises.
