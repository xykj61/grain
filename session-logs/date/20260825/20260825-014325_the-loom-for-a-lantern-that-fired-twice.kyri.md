think The meter counts a line whose first non-blank characters are // and nothing else. It undercounts a trailing comment after code on purpose, because finding that one needs to know whether the slashes sit inside a string, which is parsing rather than scanning. An honest smaller number under a falling ceiling beats a larger one that might be wrong about a string.

Each of those carries a meaning a reader should choose the ASCII form for.
