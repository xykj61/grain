title The name a veteran still likes
prompt Should the Grain versions of these modules-as-utilities wear the shorthand names developers already know, or should we suggest several Comlink-tendency names each -- for safety, performance, joy -- without overpromising or confusing, saving model confusion in tool selection, simple to teach yet good after thousands of uses?
think Tested the premise before answering it, and the premise mostly dissolved. Counted the authored files: Caravan 114, Comlink 86, Mantra 27, Tally 14 -- 241 in all, and NOT ONE is a coinage. abandon, abide, carry, confer, entrust, revoke, arrive, decline. The Comlink tendency's three tests have in practice produced common English, because common English usually wins clear and fun and safe at once.
obs So the choice is rarely a familiar name or a warm one. It is a familiar name used honestly versus a familiar name used misleadingly, and those two are told apart by whether the thing does what the name already means.
obs The rule that follows is one sentence with one hard test: wear the common name when you keep its promise, take a new name the moment you do not -- and the test is not is our API different, since every API differs at its edges. It is would a developer assuming the familiar meaning write a correct program.
obs The awk finding from this morning is exactly a NO on that test. dawk and toybox's awk both count codepoints where POSIX awk in the C locale counts bytes; an awk we grew that did the same would be correct and would still break a program written on the old assumption. By this rule such a thing does not get to be called awk. The study's abstract argument had a concrete case waiting for it, found four hours earlier.
obs On the multiple-names half, the tree already has the law -- alias-sameness, seated for Surf and Skate -- and its own conditions answer the question: peers, one implementation, one refusal path, no wrappers. Those conditions FAIL where behaviours differ, so aliasing a familiar name onto different behaviour is refused by a law we already keep, not by a new opinion.
obs And Keaton's own worry about model confusion lands here rather than anywhere else: two names for one tool is a coin flip an agent makes on every call, with no feedback about having chosen wrong. That is a real per-lap tax on every ship and argues for aliases being rare and load-bearing rather than offered by default.
obs Single-stranded refuses the shortlist directly. Three candidate names per module is a braid every reader must hold until someone cuts two, and in the meantime documents and habits form around whichever the writer liked. One name, chosen when the behaviour is known -- which is the language's own growth law, a rune is earned by a law.
obs The study names NOTHING, deliberately, and says so as its last section. Naming an unbuilt utility today would be the exact thing it advises against, and a study that broke its own rule in its own final paragraph would deserve none of its earlier paragraphs.
obs The card needed 650 bytes it did not have, so the three fetch blocks folded into one paragraph -- their detail lives in gratitude/README.md and three thanks pages, which is where a catalogue belongs rather than on an operator card.
