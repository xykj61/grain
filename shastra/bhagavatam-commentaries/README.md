## One question

The seven-work Sandarbha set builds an architecture: what can be trusted, what that trust
discloses, and what a person does in response. This file asks a narrower, more direct question:
**once that architecture stood complete, how did Jiva Goswami engage the Bhagavata Purana's own
text directly, verse by verse, rather than through the Sandarbhas' more systematic frame?**

## Krama Sandarbha -- a continuous commentary across every canto

Jiva Goswami is reported to have written a running commentary on the entire Bhagavata Purana,
canto by canto, drawing substantially on material already worked out across the Sat Sandarbhas.
Wikipedia's own *Sat Sandarbhas* article calls it, informally, the "seventh sandarbha" -- a
description this room reports rather than treats as the work's own formal title, since the seven
works this room already names as the Sat Sandarbhas close with Sarva-samvadini.

Where the Sandarbhas argue a position and support it with selected verses, Krama Sandarbha is
reported to take the opposite direction: starting from the text itself, verse by verse, and
showing how the architecture already built illuminates each one in turn. HH Bhanu Swami's modern
multi-canto English translation is a real, commercially available edition; a free digital text
remains something this room's own search passes have yet to find.

## Vrhad-vaisnava-tosani and Laghu-tosani -- one lineage, two authors, kept distinct

The verified source here, `shri-shri-brihad-vaishnava-toshini-bengali-of-sanatana-goswami-prabhupada-ed.-by`,
is **Sanatana Goswami's** own extensive Tenth Canto commentary -- the canto devoted to Krishna's
own earthly pastimes, and the canto every later Gaudiya commentator returns to most often. The
handed bibliography's own item names a different, later text: Jiva Goswami's **Laghu-tosani**
("small" Tosani), described as a refinement and abridgment of his uncle Sanatana's larger work.

Keeping these two names apart matters for the same reason the room's earlier citation-drift catch
mattered: a reader following this file to the verified link reaches Sanatana's own commentary,
genuinely valuable and genuinely related, standing apart from the specific text the original
bibliography named. Both stand honestly in this file rather than one quietly standing in for the
other.

## What this file leaves open

Whether Jiva Goswami's Laghu-tosani exists as a distinct, separately findable digital text stays
an open question, still waiting on this room's next search pass. A future pass, or a direct browse of
`grantha.jiva.org` by hand, is the honest next step toward answering it.

*A commentary that follows the text line by line asks a different patience of its reader than an
argument that builds toward one destination -- the patience of staying with each verse long enough
to let it speak before moving to the next. What this room's architecture proved in principle,
these commentaries were written to prove again, one line at a time, for as long as the text itself
runs.*
