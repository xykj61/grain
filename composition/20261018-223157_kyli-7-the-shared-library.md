# Kyli 7 -- the shared library

**Stamp:** `20261018.223157`
**Voice:** Kyli (Teacher Style, Door setting)
**Status:** Living
**Room:** mixed

---

The clean-slate tree showed what this one could have looked like if we had written it
from nothing. A `context/` folder with five files instead of forty. Each voice page
pointing at a shared library. Each move stated once.

Kyli 7 is the name for bringing that pattern home.

It is not a rewrite. The field tree keeps its full machinery -- 40 rule pages, 173
guards, the fleet, the ledger, the calendar. What changes is the composition layer:
a `context/styles/lib/` folder with the core moves stated once, voice pages that
compose from it, and a Radha style page that carries the devotional register this
tree had been missing.

The version number marks the seventh arrangement of voices and styles since the tree
began. The shared library is the keystone: once the moves are stated once, every voice
and style page composes from them, and the structure carries itself forward.

What the clean-slate tree taught, said plainly: trust the sentence. Stop one sentence
earlier than you think you should. The field tree's own rules already say that -- Gauge's
first rule is "don't be too smart about it" -- and the composition pattern is what makes
the rules and the practice agree.

Radha prema bhakti is the new door. Love first, then the argument. Passed studies only.
Sincerity over ornament. The tree had Radiant for warmth, Twilight for the threshold,
Bhakta for the open door, and Teacher for the classroom. It lacked a register for
devotion as love. Radha fills that seat.
