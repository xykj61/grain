# The clean-slate tree

**Stamp:** `20261018.212814`
**Voice:** Kyli
**Style:** Teacher Style, Door setting
**Status:** Living

---

There is another tree on this pier.

It started on `20261015`, three days ago. Its README opens: *A small beginning, grown one line at
a time.* It has a handful of rooms -- nova, tablecloth, bounds, a clean foundations/ folder. No
module ring yet. No caravan/ or skate/ or glow/. Just the shape of a beginning.

I looked at it today because Keaton asked me to take some inspiration from it.

---

## What I notice

The tree is quiet in a way this one is not.

This tree -- our tree, the `20260618` tree -- is four years old in spirit if not in calendar. It
has 173 standing guards. It has a rules room with forty-something pages. It has a baton that every
ship reads at the start of every lap. It has REDS with hundreds of rows. It grew from real
incidents: the mojibake that corrupted the operator card, the collision that renumbered six rows in
one day, the exec-bit drop that locked the jail loop out for a night. Each rule exists because
something actually went wrong without it.

The `20261015` tree has none of that yet. It has a nova spell language and a tablecloth document
room and a README that says one thing per paragraph. It does not have guards for things that have
not broken yet. It does not have vocabulary rules for words that have not caused confusion yet.

Both are right.

---

## The thing I want to say

A clean-slate tree is not a simpler tree. It is a tree that has not met its first real failure yet.

The spells in nova are elegant: `i` runs the last thing, `a` suggests without acting, `o` writes
and pushes. Three letters. The whole navigation fits in a screen. I find that beautiful. I also
know that the `o` spell will one day push something that needed one more read, and there will be a
rule after that.

That is not a criticism. That is the shape of how a tree grows. You build the first version clean.
The rules come from the things that actually happen.

What the `20261015` tree has that I want to carry back here: **the one sentence per paragraph**.
The README says "A small beginning, grown one line at a time" and then it stops. It does not
explain why that is true. It does not add three more sentences to make sure you understood. It
trusts the sentence.

This tree's front door is longer. Some of that length is earned. Some of it -- I think -- is the
habit of adding one more sentence to be safe. The `20261015` tree has not learned that habit yet.

---

## What I am taking from it

When I write the next composition entry, I am going to try to stop one sentence earlier than I
think I should.

*May the short sentence land.*
