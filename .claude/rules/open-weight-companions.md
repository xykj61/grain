## Why this page exists before anything is built

Grounded in [`external-research/20260920-021139_harness-letta-open-weight-dst-alignment.md`](../../external-research/20260920-021139_harness-letta-open-weight-dst-alignment.md),
which studied dsh, OpenCode, Cline, Aider, and Letta beside four current open-weight models
(GLM-5.3, Kimi K3, Qwen3.8, DeepSeek V4). The full rationale for each clause below is written out
in [`open/HARNESS_RATIONALE.md`](../../open/HARNESS_RATIONALE.md); this page states the rule in
the compressed form every other `.claude/rules/` page uses.

## What a companion-model session would satisfy, if one ever ran here

1. **Signed, always.** [`git-signing.md`](git-signing.md) applies exactly as written. Every
   commit stays GPG-signed under the pier's own key, whatever model authored the change.
2. **Honest provenance.** [`session-log-provenance.md`](session-log-provenance.md)'s `provider`,
   `product`, and `model` fields name the real model and product -- a GLM- or Qwen-authored
   session records itself exactly as such, on the same footing every session already keeps.
3. **The mechanism sentence, in whatever voice.** [`mechanism-sentence.md`](mechanism-sentence.md)'s
   wall welcomes a commit body that names its own mechanism before its metaphor, from whichever
   model wrote it -- the wall reads the commit, not the author.
4. **Reds-first, witness before narrative.** [`reds-first.md`](reds-first.md) and every other
   witness discipline in this tree apply unchanged. A companion model's work earns exactly the
   trust any claim earns: proof on metal, from a witness that runs GREEN.
5. **Clean-room study, honored the same way.** [`gratitude-licenses.md`](gratitude-licenses.md)'s
   discipline extends to a companion model's own weights and license terms exactly as it already
   extends to seL4, TigerBeetle, and every other project this tree studies -- read the license,
   per file if need be, before trusting a summary of it.
6. **Memory leans on Mantra.** Any session memory a companion-model harness wants stays inside
   this tree's own Mantra weave, the same reasoning [`open/HARNESS_RATIONALE.md`](../../open/HARNESS_RATIONALE.md)
   gives for preferring Mantra's signed, replayable temperament over an imported, self-editing one.
