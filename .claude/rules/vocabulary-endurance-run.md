# Endurance run -- the standing roster's two exercises

**Canonical:** `context/LEXICON.md` -- **cold endurance run / hot endurance run**. Seated as a rule `20260915` after a measurement found the molt stalled for want of one.

In living prose, rules, session logs, seat prompts, and commit messages, the standing roster runs a **cold endurance run** and a **hot endurance run**.

| Prefer | Rather than |
|--------|-------------|
| **cold endurance run** -- establishes the inherited tree's stamina before work | cold pass |
| **hot endurance run** -- exercises the staged proposal on its moved footing | hot pass |
| **endurance run** where the temperature is already clear | the pass |

Both run owed proofs. A content-keyed build may spare an identical recompilation; it never fabricates a proof.

## Why the elder word was worth leaving

**A pass is something a thing DOES or FAILS; an endurance run is something a tree UNDERGOES.** The roster is not asking whether one guard answers green -- it is asking whether a whole tree still stands after 371 guards in a row. The elder word borrowed the vocabulary of a single check and applied it to the exercise that contains hundreds of them, so *the pass failed* could mean one guard reddened or the tree fell over.

## What this does not retire

- **The machine flag `--hot` stays compact**, exactly as the Lexicon row says. A flag is typed, and `--hot-endurance-run` buys nothing a reader needed.
- **`construction/REDS.md` and `construction/CHECKPOINTS.md` keep the elder words**, since a ledger row records what was written when it was written and a checkpoint ledger is append-only.
- **Dated testimony keeps every word it wrote** -- measured `20260915`, **717 files** carrying the elder words are dated logs, folded shelves and archived accounts, and not one is swept.
- **Ordinary English about passing** is untouched: a witness still passes, a guard still passes, a commit still passes the hook.

## Why it needed a rule, which is the whole lesson

**The molt was seated in the Lexicon and nowhere else, and it stalled there.** Measured `20260915` across all eight ships: each tree read **178 or 179** occurrences of the elder words and **60** of the living one, agreeing to within a single file -- so the molt never "failed to reach a tree" at all. Eight checkouts of one repository cannot disagree about tracked bytes; they disagreed with the *intention*, uniformly.

What the elder words actually stood on was **5 living files** against those 717 of testimony. A Lexicon row is a definition a reader looks up; a rule room is what a lap reads before it writes. Every other word this tree has molted carries a rule page -- [`nib`](vocabulary-nib.md), [`red over bug`](vocabulary-red-over-bug.md), [`first resident`](vocabulary-first-resident.md), [`aroma`](vocabulary-aroma.md), [`dependent`](vocabulary-dependent.md), [`survey`](vocabulary-survey.md), [`flaky`](vocabulary-flaky.md) -- and this one carried none.

**The measurement to run rather than trust**, since both figures move as testimony grows:

```
git grep -liE 'cold pass|hot pass' | wc -l
git grep -liF 'endurance run' | wc -l
```

## Accrete-never-break

Swept on living surfaces `20260915`; dated testimony and commit history keep every word they wrote. This rule governs what is written from here forward.
