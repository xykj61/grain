# "molt" — the prep pass for living mutants and their fossils

**Seated:** `20260808.190142` on Keaton's word · **Status:** Living

When Keaton says **"molt,"** walk the tree for dated writings ripe to become a **living mutant**, and seat each resulting **writing fossil** onto the shred-prep list — opening **no cut**. Where **survey** is the looking pass before the first GREEN and **shred / shed** is the authorized cut, **molt** is the *prep between them*: it readies new versions and marks the old ones for later shedding, without destroying anything.

The vocabulary this rides on is already seated in `context/LEXICON.md`:

- **living mutant** — an accrete copy of a dated writing at a **new one-clock stamp** that becomes the living path; the prior file stays a **writing fossil**.
- **writing fossil** — the dated original kept on disk after a living mutant seats (accrete-never-break); its Status banner points to the living path.
- **shred-prep list** — the living pin `work-in-progress/SHRED_PREP.md`, Classes A · H · O.
- **shred / shed** — the eventual Amphora cut, which stays **RED** until Keaton circles it.

## What "molt" does, in order

1. **Walk** — scan for dated writings whose living intent has moved on and that are candidates to be re-seated as a living mutant at a fresh live-clock stamp (`TZ=America/New_York date`). For `foundations/` writings, run the **transitive writing crawl** first (BFS outbound relative `.md` links to leaves) before proposing any mutant.
2. **Seat the mutant** — when Keaton's word (or an already-standing seat) authorizes it, write the living mutant at its new stamp and leave the fossil on disk with a Status banner pointing to the living path.
3. **Prep the fossil** — add the fossil to `SHRED_PREP.md` under **Class H** (horizon writing fossils replaced by a living mutant). Prep only.
4. **Open no cut** — molt never shreds. The cut waits for a circled **shred / shed** and its Class O word-scope. Custody first: build nothing that destroys.
5. **Leave a record** — a molt pass writes a session log; on **send** it ships.

## What "molt" always keeps

- **Prep, never cut** — molt books Class H entries and seats mutants; it never opens the Amphora shred. `shred / shed` is a separate, circled word.
- **Accrete-never-break** — the fossil stays on disk until a circled shred proves parity. Overwrite-in-place of a living name is **not** a molt and **not** a shred.
- **Live clock** — every mutant's new stamp is read from the live host clock, never fabricated (`[[live-clock-stamps]]` · one-clock law).
- **Measurement beats memory** — the shred census (`tools/fixtures/shed_census_scan.sh`) is authority for Class O membership, not recall.

## Why the word exists

A tree that grows in the open keeps re-seating its best writing at fresh stamps, and the old copies pile up honestly on disk. "molt" is one syllable for the whole tending gesture — grow the new skin, mark the old one for shedding — so a routine sweep readies both the living edge and the shred-prep list without ever reaching for the knife.
