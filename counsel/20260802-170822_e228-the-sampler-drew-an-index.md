## A bug caught by running the thing

The walkthrough sampler drew `active-designing/README.md` this round and
reported **inbound=703**. The number is nonsense on its face, and the cause
is plain once seen: the sampler counts references by basename, and the
basename of that file is the word **README**, which appears in seven
hundred and three files across the tree. It was measuring a word, not a
file.

Worse than the wrong number is the wrong question. A README is a **living
index**, not a dated artifact; the ritual's four verdicts — update,
archive, yonder, queue — are shapes for dated work, and none of them
belong to a room's own front page. So the sampler now skips it, with the
reason written into its own header where the next reader meets it beside
the shelf.

**The bug surfaced because the tool was run rather than trusted.** Three
rounds of clean samples had passed without it appearing; the draw is
random, and a rarely-drawn file hides a flaw for exactly as long as luck
allows. Running the instrument every round is what found it.
