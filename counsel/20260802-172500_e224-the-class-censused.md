## The finding that changes the recommendation

While counting, the number moved under the counting hand. `e137-recursion` read **one** inbound reference when it was first flagged, and reads **four** now. Nothing about how the tree uses it changed; what changed is that counsel wrote about it — the e222 seat, the e223 seat, and a fusion baton each mention it by name, and each mention is an inbound reference.

**The census was perturbing itself.** A file proposed for the queue becomes, by the act of proposing, better referenced than it was — which would eventually make every candidate look load-bearing for exactly the wrong reason. The fix is small and lands with this seat: reference counting now **excludes `counsel/` and `expanding-prompts/`**, the two rooms where discussion lives, so the count measures how the tree *uses* a file rather than how often we have talked about it.

## Counsel withdraws its own proposals

With the shelf measured whole, the earlier queue verdicts on `e137-recursion` and `e147-recursion` are **withdrawn**. Three reasons, in the compass order.

Safety first: these are dated testimony — the season's own breadcrumb trail — and the tree's standing instinct is that dated artifacts stay. Nothing here is a hazard, a secret, or a duplicate. Performance second: twenty-nine kilobytes is not a cost worth a gated instrument, a written queue, and a word from Keaton; the effort of removing them exceeds the weight of keeping them by a wide margin. Joy third, and honestly: a reader tracing how this season actually moved will thank the trail.

**The class is ruled a standing KEEP** — which is a verdict, not an absence of one — and the real problem it was raising was never storage. It was that the sampler kept re-finding the same shelf every round.
