## Why this guide exists

An Opus (or Cursor Cloud) sitting often starts from a **depth-1 clone** with **no** `vendor/zig-toolchain/`. That directory is gitignored on purpose -- local by design, never cloned -- yet `rye/lib/*` already symlinks into `vendor/zig-toolchain/lib/...`. A raise that only installs Zig, without restoring that exact shape, leaves bootstrap staring at broken links.

This guide names the shape that printed GREEN: **Zig lib as a directory symlink**, plus a tiny **`zig` wrapper** that execs `python3 -m ziglang`. The July 15 cloud-agent recipe still stands for Cursor Cloud; this page accretes the Opus-measured seam beside it.

## The recipe (measured GREEN)

Exit codes below were captured **before any pipe**. Re-run on your own metal; state no measurement you did not just run.

```bash
# From the clone root (example: /workspace)
pip install ziglang==0.16.0 --break-system-packages
# exit 0

# Resolve the package home (path varies by user vs system site-packages)
Z="$(python3 -c 'import ziglang,os;print(os.path.dirname(ziglang.__file__))')"
# examples seen:
#   /usr/local/lib/python3.12/dist-packages/ziglang
#   /home/ubuntu/.local/lib/python3.12/site-packages/ziglang

mkdir -p vendor/zig-toolchain
ln -sfn "$Z/lib" vendor/zig-toolchain/lib
printf '#!/bin/sh\nexec python3 -m ziglang "$@"\n' > vendor/zig-toolchain/zig
chmod +x vendor/zig-toolchain/zig

# Prove the lib target answers before bootstrap
ls vendor/zig-toolchain/lib/std >/dev/null

export RYE_ZIG="$PWD/vendor/zig-toolchain/zig"
sh rye/bootstrap.sh
# rye 20260618.193812 - backend zig 0.16.0 - exit 0

# Required before emit -- omitting mkdir exits FileNotFound on the bin path
mkdir -p rishi/bin
rye/bin/rye build rishi/src/main.rye -femit-bin=rishi/bin/rishi
# rishi/bin/rishi ~= 12.8M - exit 0

# Ripgrep: succeeds with no update and no 403 workaround on measured Cloud images
apt-get install -y ripgrep
# exit 0 - rg on PATH

# Smoke: always give rishi run a .rish argument -- never bare, never --help as the script
rishi/bin/rishi run tools/glow_run.rish glow/gen/cast-u32.glow
# GREEN - exit 0
```

### Why the first attempts fail

| Miss | What breaks |
| --- | --- |
| Symlink the package root without a `lib/` child named for `rye/lib/*` | Bootstrap's `--zig-lib-dir lib` follows dead links into ignored `vendor/` |
| Expect `vendor/zig-toolchain` to arrive with the clone | `/vendor/*` is gitignored except `genode` and `monocypher` -- toolchain stays local |
| Emit `rishi` without `mkdir -p rishi/bin` first | FileNotFound on the emit-bin path (e141 counsel correction) |
| Run bare `rishi run` or `rishi run --help` | Shell refuses: script must end with `.rish` |
