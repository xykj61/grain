## What earns a place here

A reference ships once **every form in it has been run before it was written down**. That is the
same bar [`../tutorials/README.md`](../tutorials/README.md) holds its own room to, and it is a
promise about your next twenty minutes rather than a note about house style. A reference earns one
thing beyond that bar: it names the **edges**, the inputs a form refuses and what it answers when it
does. That section is the part a reference usually leaves out, and it is the part a reader reaches
for at the moment they most need it. So the bar here stays a running one: type the line, watch it
answer, write down what it answered.
