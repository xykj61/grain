The code is a plan. This page seats the name. The program is not in the tree yet.

When the program is written, it keeps three habits.

The top of the file speaks in a voice a newcomer can follow. One sentence says what the window is for. That is the Door.

Each bound says why the number is that number. Twenty-four rows and eighty columns, because that is the grid Dexter already draws, and a line past the grid is refused. That is the Meter.

The green line, when a small example command works, is allowed to be glad. That is the daylight voice. The gladness comes after the check, not before it.

The first command is a small one. It prints one green word and stops. It does not reach the network. It does not hold a key. It does not install anything on a phone.

The heart of the work, on `foundations/20260628-121512_the-heart-in-the-work.md`, is to keep energy rather than scatter it. Sill keeps one window, one prompt, and one answer.

A later seat writes the program. This page keeps the name.
