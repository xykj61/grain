## What earns a place here

A tutorial ships when **every command in it has been run before it was written down**. That is not a style note. The elder first-hour page in [`../../manual/`](../../manual/README.md) told readers for months that the tools *"came with the copy"* when a fresh clone carried neither (REDS %117) -- a claim nobody could check without doing the very thing the page was meant to make possible.

Drafts live in [`../../edu/`](../../edu/README.md) until they meet that bar.
