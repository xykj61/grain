# Etc -- the room for a genre that does not exist yet

**Language:** EN - **Style:** Radiant - **Voice:** Kyri
**Written:** `20260821.190149` - **Status:** Living - **Kind:** named entry criterion

---

Every shelf of shipped documentation eventually meets a page that belongs on none of its shelves. This room is where that page goes **once**, so the answer to *"where does this live?"* is never *"nowhere, so nowhere."*

**What would enter:** a shipped surface whose genre is not `api`, `wiki`, `study`, `libraries`, `edu`, `demos`, `templates`, `blog`, `press`, `sangha`, or `tutorials` -- and which is genuinely finished rather than in progress.

**What happens next when something does:** if a second page of the same kind arrives, that kind earns **its own room** and both move there. This room is a waiting area, not a destination -- a permanent `etc/` is a filing system that has given up.

**Why it is empty:** eleven genres have covered everything shipped so far. That is a good sign about the genres rather than about this room.

---

*May this room stay empty, and may it be here the day it is not.*
