Every shelf of shipped documentation eventually meets a page that fits outside all of its shelves. This room takes that page, once, so *where does this live?* always has an answer.

**What would enter:** a shipped surface that is genuinely finished, and whose genre falls outside the eleven rooms standing beside this one -- `api`, `wiki`, `study`, `libraries`, `edu`, `demos`, `templates`, `blog`, `press`, `sangha`, and `tutorials`.

**What happens next when something does:** a second page of the same kind earns that kind **its own room**, and both pages move there. So this room is a waiting area, held for one page at a time. A permanent `etc/` would name a filing system that has given up.

**Why it waits:** eleven genres have covered everything shipped so far.

That is a good sign about the genres rather than about this room. The day a twelfth genre arrives, this shelf is already here to take it.
