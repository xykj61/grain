## Laws

- **Accrete-never-break** — dated sources stay; geode pages are compiled outputs + living indexes.  
- **Bidirectional relative links** — wiki and guides link both ways where a pair exists.  
- **Radiant · time-linted · happy zone · sameness macro · single strand · hammock** — Geode Season enforces these before a page is “crushed in.”  
- **Round budget** — Geode Season N is an **explicit bounded power of two** (lean **16** = 2⁴; extend 32 · 64 · 128 only).  
- **No live shred / deploy / wallet / gas** from crush alone.
- **Build stack** — docs-geode sits above glow·tend and below Aurora·Caravan·Tally; crush does not skip foundations ([`../context/LEXICON.md`](../context/LEXICON.md) · build stack).
