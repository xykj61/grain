## A file is a named stack of words

A **file** is a bundle of text with a name. `README.md` is a file. The letters after the last dot
are the **extension**, and they hint at the kind of file.

- `.md` -- prose a person reads. Markdown: ordinary sentences plus light marks for headings and lists.
- `.rye` -- Rye source. Instructions the compiler turns into a running program.
- `.rish` -- a small program Rishi runs. Many witnesses live here.
- `.kyri` -- small durable facts. One field per line.

You open a file. You read it. You close it. The name stays. The contents change when someone writes
and saves.

A **folder** (this tree often says **room** when the folder has a job) is a named place holding
files and other folders. `context/` is a folder. The slash is a path mark: "look inside."

`context/BHAKTA_STYLE.md` means: start at the tree's root, enter `context`, open the file
`BHAKTA_STYLE.md`.

A **path** is that address. Absolute paths start from the whole machine. Relative paths start from
where you are standing.

That is enough file-system to read the front door.

---

## Git keeps the history of the house

**Git** is a program that remembers every saved moment of a folder.

Each saved moment is a **commit**: a snapshot of the files, a short message saying what changed, and
a name for that snapshot -- a long fingerprint of letters and numbers. On this tree those commits
are **signed**. A signature here is a seal saying "this snapshot came from a key this person holds."

A **repository** -- a **repo**, a **tree** -- is the folder plus that history.

A **clone** is a copy of the repository on another machine, history included.

A **remote** is a named address git uses to talk to another copy. On the living field the speed-dial
names are already seated: `xy` for the field, and a name for the public seed. You will meet those
when hands touch the network. Today they are landmarks.

`SOURCE.md` splits the journey in two on purpose. Part One gets you a working desk. Part Two is
where keys arrive. **Custody before capability**: first a place to stand, then the seals.

## Page by page on the porch

Open them in this order. An hour of reading is enough.

### `README.md` -- what this is, and what already runs

The greeting. It tells you Grain is a free environment you download, and that your words and your
name are meant to stay in your hands. It uses Two Rooms in public: a page describes what runs today,
or what is designed and intended, and it says which.

At the bottom of a first reading you want three facts in hand: what Grain gives a person, what
already runs, where to start.

### `MAP.md` -- the house in one glance

The floor plan. Seven rooms. Three doors if you open only three: `README.md`, `SOURCE.md`,
`manual/`. The map is for humans; models are pointed at `llms.txt`.

The map also names **two floors of the library**. **Open shelves** are walked by default:
`context/`, `foundations/`, the standing rules, the tops of the workrooms. **Closed stacks** open by
a named path or a citation: dated shelves, archives, the reading room. Closed governs the walk. A
call slip still opens any stack. Nothing is hidden -- the walk is ordered so many hands stop paying
for the same stroll.

`construction/ITINERARY.md` is what is true right now. `construction/REDS.md` is what was learned by
missing.

### `SOURCE.md` -- from nothing to a signed home

The path with a hinge in the middle.

**Part One, the first day.** A living place for the code. Git on the machine. A clone of the tree.
An editor started inside a bounded enclosure so an assistant works in the project folder and stays
there. Part One ends when that desk answers.

**Part Two, the signed home.** Keys. A key to knock with (**SSH**: how one machine proves itself to
another). One seal for your name (**GPG**: how a commit carries your mark). Signing inside the
sandbox, so an assistant can seal work without reaching the rest of the machine.

The hinge is the whole teaching. A **sandbox** -- this tree also says **Pond** -- is a gentle
enclosure. The program inside sees what it is granted, and the rest of the machine stays yours.

Keys wait for Part Two because a key is custody. Grain wants you standing in the house before you
cut the seals.

### `ORGANIZING.md` -- where a new page goes

The sorting rule. Read a piece aloud and ask what it *does*. Governing decisions go to `context/`.
Teaching goes to `manual/` and `docs-geode/`. Implementation goes to the module that owns that verb.

### `CONTRIBUTING.md` -- how a change arrives

Small. Signed. Prefixed with the component it touches. Written as prose a person can read in the
log.

## Two Rooms, seen on the porch

You now have enough to use the label.

A sentence in the README naming a count of witnesses on metal belongs to the **running room**. A
witness produced that number.

A sentence naming full-OS boot as a bright horizon belongs to the **designing room**. It is wanted.
It is still ahead of a witness.

Both sentences can live on one page. The page tells you which is which. That is the courtesy the
front door extends: you always know which floor you are standing on.
