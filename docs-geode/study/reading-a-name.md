## The two marks

A name here answers two questions and keeps them apart on purpose. **The stamp says when.**
**The name says what** -- and it promises only what the work can keep.

## The stamp

Open any log on this shelf and you meet a filename like this one:

```
20260905-154954_the-clock-and-the-mark.md
```

Read it left to right: year, month, day, then hour, minute, second, then a short **sprig** naming
the piece. The whole shape is `YYYYMMDD-HHMMSS_sprig.ext`, and every stamp comes from one clock, so
a later stamp is always a later thing.

That single property earns the whole form. The name sorts the same way in a terminal listing, in
`git log`, in a file browser, and in your own head -- one order, everywhere, permanently.

In a sentence the same stamp wears a dot: `20260905.224930`. One clock, two spellings -- a hyphen
in a filename, a dot in prose.

## When a room folds, the name still works

A room that outgrows a reader folds its files onto day shelves, `date/YYYYMMDD/`. The day then
appears twice, once in the folder and once in the filename, and that repetition is deliberate.

Because the day rides in the basename, the new home is *computed* from the name alone: read the
first eight characters and insert `date/YYYYMMDD/`. A link written before the fold therefore still
resolves, and you can watch it happen in a minute at [the demos page](../demos/README.md).

## The name, and the number it declines to carry

A mark is a stamp and a name. Written out, a piece of work reads:

> the standing movement (20260821-142939)

The mark stops there, and the step number it might have carried stays out on purpose. This tree
marks planned work by stamp and name, then counts the steps afterward with `git log`, because **a
number written into a name is a forecast**.

The evidence is the tree's own. One ladder announced sixty-four steps in its name and reached
three; eight more were measured the same way, and the pattern held. Every one of those names was
written in good faith -- a forecast inside a name simply reads like a fact once it is written.

## Two numbers that do keep their place

**A waymark is a name.** HAWM, STOA, BUHR -- four letters drawn once for a ladder, a name rather
than a count, and each keeps its draw.

**A census keeps its place.** The `%N` on a row of the reds ledger counts work already finished, so
it stands exactly as written. A gap in that spine would mean a record had gone missing, which is
worth being able to see.

The sigil is `%` rather than `#` for a plain reason: GitHub turns `#438` in a commit message into a
link to pull request 438, which would carry a reader somewhere the sentence never meant. In Glow,
as in the Hoon it descends from, `%` marks a constant term -- a value that is exactly itself -- which
is what an immutable ledger row is.

## The test you can carry

Before writing a number into a name, ask one question.

> **Could this number turn out to be wrong?**

Work already done: no. The number is a census, so write it.

Work still planned: yes. Mark it by stamp and name, and count the steps when someone asks.
