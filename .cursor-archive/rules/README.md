# Cursor rules -- retired, held whole

**Status:** Fossil -- **Retired:** `20260920.135100` on Keaton's word -- **Checkpoint:**
`construction/CHECKPOINTS.md`, walk-back nib `efa58efff4`

The 60 files in this room are every `.cursor/rules/*.mdc` this tree ever carried, moved here
whole rather than deleted -- a **working-tree debride** per [`../../.claude/rules/debride.md`](../../.claude/rules/debride.md).
Cursor has stepped outside the working rhythm this tree serves now, so `.cursor/rules/` -- the
path Cursor itself reads -- stands empty, and this bench carries one edit per rule going
forward, rather than two.

## What this room keeps whole

**Every byte survives.** Each file here is exactly what stood at `.cursor/rules/<name>.mdc` the
moment this molt landed, and git history keeps every earlier revision too, back to each file's
own first commit. The move touched paths, and left history exactly as it was.

**Read the file here for the true record.** A handful of `.mdc` twins were **compressed
rewrites** rather than byte-identical copies of their `.md` canon --
[`ascii-first.mdc`](ascii-first.mdc) is the clearest example, holding a shorter prose pass over
the same law. Should Cursor, or a dual-editor discipline, ever return, this archived file is the
fuller record, and the `.claude/rules/` canon alone tells only half the story.

## Why archived rather than shredded

[`debride.md`](../../.claude/rules/debride.md) distinguishes a working-tree debride (removed from
the living tree, kept on disk and in history) from a deep debride (stripped from history itself,
force-pushed). Everything here is ordinary documentation about a retired convention -- no secret,
credential, or legal exposure among it -- so the lighter cut is the honest one.

## If Cursor returns

Every `Canonical Cursor twin: ...` pointer this tree's rule pages once carried was removed in the
same round that filled this room (`construction/CHECKPOINTS.md` `20260920.135100`). Reviving a
twin means writing a fresh one against the current `.md` canon, treating these files as a
starting draft -- the `.md` pages have moved on in the months since most of these were last
touched, and a fresh pass would serve better than a verbatim restore.
